# 上游动态修复的设计原则

上游修复的目标是减少 OCR 初级结果和确定性分析造成的结构错误，同时保持内容
完整、来源可追踪和增量交付。这里的“动态修复”指由真实失败指导通用规则改进；
运行时不针对书籍保存补丁，不自动改提示或在线调阈值。

## 固定审核标准，修复错误来源

送修多可能因为上游错误多，也可能因为审核误判多。两者必须分开核验。改变阈值
只能改变调用量，不能证明内容变好。比较上游版本时，原始 OCR、JEV 协议、模型、
服务和工作点应保持一致。运行时采用经验证的局部协议，阈值由库内部固定，不作为
用户控制精修成本的配置项。

修复应落在制造错误的模块。OCR 框、阅读组和自然段是不同概念：同一阅读组中的
竖排列框也需要经过续接判断，不能直接当作多个独立段落。相应修复应复用段落
连接契约，保留原有来源顺序，不另建一套全页排序。

少送一页不等于修好一页。验收必须先确认来源身份、原文、框和顺序没有丢失，再
检查结构决定。不能通过删除应审核的内容、改写标签或降低审核标准来获得改善。

OCR 已将真实脚注标成正文，且另一轮没有恢复其独立来源时，若缺少可靠的确定性
修复依据，应交给 JEV 与 LLM 精修。这类成本属于正常恢复路径，不以增加启发式
规则强行消除。肉眼核验应同时对照原页、原始 OCR 和当前投影，分别记录 OCR
结构错误、页面处理错误、审核误判及尚未确认的问题；同一页可以同时存在多类问题。

评估确定性处理是否收敛，应单列确认可由算法修复的问题页数及其占全样本的比例，
同时保留总送修比例。排除已确认的 OCR 问题时，必须说明分母及混合问题的处理；
尚未核验的页面不能当作正常页或已接受的 OCR 问题。抽查结果不等于全样本错误率。

## 资产关联不能删除审核证据

独立 OCR 文本被关联为表题或表注时，仍是具有原始文字、来源编号和 bbox 的独立来源。
初级页投影保留这些来源及其候选资产、slot，不把“已关联”当作正确归属的证据。
资产块内部自带的标题、内容和说明也要提供给审核，不能只暴露表格单元格或公式主体。

JEV 分别审核独立来源；精修可以纠正归属，也可通过 `keep_asset_attachment=false` 解除
候选关联。没有候选关联时，精修请求不暴露该控制项。省略该项保留原有候选关系，不能为
没有原始目标的来源新造关联。附属文字不充当正文自然段的前驱，也不打断跨资产的真实续接。

仅在单页采用结果进入输出时合并仍然有效的同流成员，生成资产 title/caption。移到其他
阅读流、解除关联或忽略的文字不会从资产槽位重新出现。来源完整的采用页仍保留在诊断
状态中；输出组合不改写该页，也不增加全书完成屏障。关联信息是运行时投影，不进入 PCEX
字段；原有 title/content/caption 存储语义保持不变。

前置、孤立、类型不符或距离不满足的 caption，不能因为找不到目标而消失。多自然段
判定必须先检查原始换行，再压缩空白。重复的表格标签、单元格和公式结构不能按普通
重复文字直接删除；原始资产文字与图像裁剪都要保留。冻结 OCR 回归无法恢复已被旧解码器
删除的内容，必须另用结构化 OCR 输入检查 decoder 到原始页缓存的保留链路。

## 测量证据与结构决定分离

像素观测提供局部证据，段落模块决定如何采用。原始 OCR XML 保存可选观测，旧
缓存缺字段时继续既有路径；未知值保持未知，不为新规则静默改写有效缓存。

大片空白中的短数字可以补充受限的单行墨迹观测，帮助区别宽 OCR 框与实际页码字形。
观测来自未擦除的首轮图像，并在分配前限制裁剪面积；分离行、边缘噪声和不一致尺寸保持未知。
它不重写 OCR 文字或原框，不依赖封面图片，也不增加渲染或 OCR 请求。持久化位置是诊断
OCR 缓存，JEV 能看到观测；PCEX 来源位置契约保持不变。

多行 bbox 不能证明首行缩进。首行缩进来自实际墨迹行带相对后续完整行的测量，
多条后续行需要形成多数一致的基线。单行几何、句尾标记和缩进必须联合使用，
不能凭一个句号或一个窄框强制断段。

竖排方向也不能只由高窄外形决定。文字密度、CJK 比例、平行框及列间墨迹留白提供
互补证据；无法区分的字格保持未知。检测到竖排列边界，只说明需要检查续接，
不意味着所有相邻列必须合并。

| 可采用的证据 | 必须保留的约束 |
| --- | --- |
| 平行竖排列框 | 标题和独立编号条目仍可另起 |
| 引号包围的数字编号 | 需要已有编号条目上下文，不切断普通数字术语 |
| 明确首行缩进 | 不切断未完词，不从多行整框猜测 |
| 独立居中的星形分隔符 | 保留符号来源；不将行内星号或左对齐的未知标记强判为分隔符 |
| 多列竖排墨迹 | 不将横排窄栏或对齐字格强判为竖排 |
| 严格纯白输入 | 浅色墨迹和不明确的透明度仍走 OCR |

测试需要覆盖这些机制的正反两面，并通过真实 decoder、缓存往返和两种脚注投影
验证接线。不能只在 helper 上通过，也不能写入书籍原句或页码作为判断条件。

左缩进的单行可以延伸到右栏边；不要求双侧缩进。句末标点后的破折号不取消已有
缩进证据，但破折号本身不能使未完成词句成为可断边界。仍优先使用实际像素观测，
并保持同栏、先后关系和资产边界限制。

含公式单行的宽度不由 LaTeX 源码长度推导。可用附近普通单行的一致框高确认其单行
尺度，再沿用同栏缩进判断；单一参照必须紧邻且满足更严格尺度。实测首行信息优先，
字号冲突、跨栏或多行歧义保留未知。

段落连接只由持有初级页几何的 Jointer 判断。后续格式组装不得用较弱的文字条件重新连接
它已分开的段落；从已采用分析恢复的段落也不能被重新推断。图表完全位于两个文字框之间时，
不能以“存在资产”为由屏蔽下一行可靠的缩进证据。旁置图片可能挤压行宽，保留其保护；连续
文字仍可将图片、表格嵌入同一自然段。该判断只使用已到达的本页信息，不增加前瞻或全书等待。

完整话轮或结束省略后的新报告发言不必拼入同一自然段。使用有限的报告结构与句末线索，
同时保留引语外未完成条件、后置归属语及未完成词；不把这种线索宣称为通用语法解析。

跨页连接不能把行内公式首节点等同于新自然段。只在真实跨页、前文尚未结束且不是数字
编号时沿用文字续接规则，不由此推断同页连接或吞并独立段落公式。另有短连接词与公式
并排的印刷行：公式实际结束、位置吻合且下一段有可靠缩进时，连接词不强行接到下一段。

局部版权页中的出版记录也不是普通连续叙述。单独 ISBN 形态行、版次和印数单行共同
提供记录上下文，保持其独立段界；不依赖 metadata 任务，也不改变原始文字或来源身份。

## 脚注标记与传输包装分离

明确的印刷标记可能被 OCR 写成 Markdown 转义星号，或包进 `\(…\)`、`$…$` 行内公式。
这些包装不应让同一个圈号或星号失去定义身份。注释起点和正文引用共用标记识别规则，
只有完整、已知的标记才按引用处理；普通数学表达式不能因为带相似字符就被截断。

正文只连接本页已有的对应定义，没有定义的标记保持原状。星号按完整连续串匹配，
`**` 不拆成两个 `*`；发生引用替换时，其 Markdown 转义符也属于被替换的标记，不能残留
为正文反斜杠。注释定义投影可以去掉起点标记，但原始 OCR 和来源身份继续保留。
显式转义的星号与解释文字之间不强求空格；普通 Markdown 强调语法不因此成为脚注起点。

脚注定义与正文引用分别验证。清楚的数字编号标点可以建立已有定义，即使 OCR 没留下
对应正文标记；没有明确编号标点的普通数字前缀，仍需本页正文已有明确上标引用候选支持。
Unicode 连续上标、独立的 LaTeX 上标和完整的 HTML sup 数字采用统一数字身份，多位上标
不拆成多次引用。孤立数字、年份和小数不因此成为定义，`x^{4}` 也不能按独立上标处理。
正文侧只替换已建立定义的完整标记，未匹配的原文保持不变，不补造缺失的引用。

OCR 将上标压平成 ASCII 时，可采用更窄的配对证据：英文完整句末紧贴的数字、本页唯一
的该数字候选，以及本页同号的注释定义。已存在明确上标时不推断另一处普通数字；同号候选
重复、缩写、代码和数学表达式不作恢复依据。只替换数字标记，句末标点、引号和周围文字保留。

此处提供的是局部结构假设，不是“所有上标都是脚注”的语义保证；最终归属与引用仍由
同一套 JEV 规则检查。无精修增量解析与精修初级投影共用识别规则，只保存待闭合页面的
候选，不为匹配扫描或等待全书。

这不是将普通 ASCII 数字统一判为脚注号。数字仍可能是正文、列表、小数或页码；没有充分
证据时不能据此新建定义。关闭脚注时不因这些规则建立 citation 或正文引用。

## 页边内容和可恢复的排除

第二轮 OCR 的结果不必然是脚注。短数字只有同时满足严格的局部条件，才可提出页边页码假设：
它位于全部文字的下方、完整正文栏的外侧，正文带相对数字框足够宽且足够高，不与图表或
公式重叠，也未被正文中的数字或引用标记提及。正文栏内的数字、旁边仍有文字的数字、
四位年份和不确定候选继续走原有审核，不能仅凭位置、字号或编号排除来源。

有实际多行墨迹观测时，正文带可使用较短的高度条件；单个标题或未知观测不能替代该证据。
竖排书的侧边页码不必在全部正文下方，但需至少两个实测竖排列框，且其文字量超过正文的一半。
中文逐字数字只在这个条件下提出页码假设；正文提及同号、与资产重叠等保护仍然适用。

这个假设只改变分析投影。原 OCR、原文、来源顺序和 bbox 都保留；精修初级页将来源明确
标为 ignored，JEV 仍可检查并恢复误排的阅读内容。原始来源先被完整捕获，再选择注释阅读流，
不能过滤后重编号。无精修增量解析与局部精修使用同一选择规则，真实注释续文可跳过页码
继续连接，不增加邻页、全书或元数据等待。

居中的底部页码使用另一组局部证据：数字框须接近完整正文带的中轴，宽高符合一行短数字，
与正文底部至少相隔1.5个数字框高度，并位于其余阅读文字的下方。正文数字、引用和资产重叠
保护保持不变。不能因为数字靠近页底，就接纳覆盖大面积空白的 OCR 框或排除普通注释。

短大写代码采用更窄的页边假设：需要多个足量正文块，代码整体位于正文栏外侧，
并与包括图片在内的全部正文内容留有明显下方空隙。普通图注、罗马数字、宽框、
单个字母和同时存在其他注释解释的页面不采用此假设。正文出现引用标记、疑似压平
的句末引用数字，或提及同一代码时，也保留给后续审核。规则不列举供应商或书籍的
具体代码；来源继续以 ignored 候选保留，不删除 OCR 观测。

局部窗口的脚注别名绑定必须读取未修改的初级身份快照，再写入各页的规范身份。先改掉
前页 ID、再拿它寻找原始 ID，会把已知起点的续文错误变为 unresolved。窗口内可证明的
起点继续保留；窗口外未知起点不凭空补足，也不为查身份等待其他页面。

章页脚识别同时要求页码与章号的受限格式、页边位置、充足正文和明确下方空隙。
它只建立可逆的初级假设；正文引用、其他注释或稀疏页面阻止推断。原始来源始终保留，
后续审核可以恢复；不能用删除文字的方式节省精修请求。

页边候选还可使用独立的局部证据：横排侧页码需排除首行列表对齐；自身竖向堆叠的汉字
数字仍需足量中文正文和外侧下半部位置。表格页的短代码需要充足表格、远离表格的空隙
与外缘对齐，不能据此排除近处图注或引用键。所有这些判断保留原始来源，不更改 OCR 框。

只有页边印刷物的页面需要两路互相支持的局部位置证据，正文和脚注共用投影并保留全部排除来源。

## 有直接证据时避免无效模型调用

严格纯白的渲染结果无需 OCR。判断依据是像素，而不是“内容像数字”或“文字很少”；
即使只有一个近白墨点，也继续原有识别路径。

本地和 vendor 首轮均可保存空页和几何并正常完成。vendor 脚注二轮擦除图严格纯白
时，保留第一轮正文与 usage，跳过第二次请求。未发出的请求不产生观察事件或 token，
不能模拟一次成功调用。全空输入、混合输入及两条 vendor 调度路径遵守相同契约。

渲染和图片大小保护仍先于这些观测。像素裁剪在分配前限制面积，证据被资产遮挡
时不推断，不保留全书图像，也不增加全书等待。新规则不得让 `on_body` 和
`on_footnote` 退化为文件完成后的集中通知。

## 验证结论的边界

小范围反例用于验证错误机制，完整样本用于发现规则对其他内容的影响。未经整体
核对的局部改善不能视为可采用的通用规则。完整请求相同且协议、服务一致时，可以
复用对应响应，但必须与全新请求区分；重复开发页也不等于独立书籍验证。

结果报告使用页数和明确分母，分别列出 JEV 判对和判错；假阴性和假阳性需要人工
核验。已修复旧错误的标签需要重新判断，已知正常子集没有误送不能代替完整误报率。
最终结果与验证覆盖见[自动分析验证](../verification/jev-upstream-automatic-analysis.md)。

现有规则解决的是有可靠局部证据的几何和边界问题。图注、署名、无编号脚注及装饰符
仍可能需要角色判断；现有 caption 表达也未必能保存独立文字框的来源。强行在图片处
断段会破坏穿过插图的正文，直接搬移或删除文字可能丢失来源。

正文末尾的 ASCII 数字可能是脚注号、普通编号或小数，不能统一剥离。无法无歧义
恢复时保留既有路径或交给下游审核。关闭脚注的既有样本上，通用几何规则的收益已收敛，不构成
所有 PDF 的正确性保证，也不构成网站整体成本保证。

审核对象和判定标准见[JEV 结构审核](jev-structural-review.md)。
