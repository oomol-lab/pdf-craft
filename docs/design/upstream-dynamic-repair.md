# 初级页面分析的设计约束

初级页面分析把 OCR 的来源观测组织为阅读流、自然段及脚注关系。代码能确定的局部事实
先由代码处理；需要语义判断的歧义交给 JEV 和按需 LLM 精修。目标是保留内容和来源，
减少错误，而不是通过隐藏来源压低精修调用量。

## 来源与决定分开

来源记录保存原文、原分类、身份、阅读位置和 bbox；归属、段界和引用是可以被精修
改正的决定。排除页码或出版附属物只改变投影，不删除来源，也不在过滤后重新编号。
这样下游能审查并恢复误排内容，缓存和错误定位仍有稳定依据。

原始 OCR 不随精修或输出组合改写。脚注标记的转义、行内公式包装与内部定义索引分开
处理，不能把格式包装当作新身份，或补造 OCR 没有识别出的引用。

## 局部证据与保守处理

框、阅读组和自然段不是同一概念。阅读顺序保留已有栏序，不能用全页纵坐标排序交错
两栏。段界联合使用已有几何和可靠观测，不用单个标点、窄框或“看起来像注释”作决定。

像素观测只提供证据，不直接替代归属判断。多行整框不能证明首行缩进，高窄外形不能
单独证明竖排；未知观测保持未知。裁剪在分配前限制面积，不保留全书图像或增加整书等待。
只有严格纯白的输入才能直接跳过 OCR；浅色墨迹仍走识别路径，未发出的请求不计 usage。

真正缺失的 OCR 文字无法由这些结构规则恢复。不能增加书籍特定补丁，或用启发式强行
覆盖缺少证据的语义问题。开启、关闭脚注共用确定性能力，按模式选择是否建立脚注关系。

## 资产文字不能消失或复活

独立表题、图注和表注即使关联到资产，仍保留自己的来源身份、原文与几何。找不到目标
的 caption 保持独立来源，不能静默丢弃。资产内生 title/content/caption 也须进入审核证据；
图片的非展示 content 不因此变为展示文字。

初级候选不是编辑权限。精修可以按稳定资产身份新建、解除、重定向关联或改变 title/caption 槽位，
也可以把内生展示文字恢复到正文/脚注。目标须是最终当前页中真实保留的资产，双方的正文/脚注归属
及脚注身份须自洽，文字不能同时被忽略或作为图像保留；程序不依据初级语义批准关联。
同一来源可以切分后分别归属，多个来源可按最终顺序组成说明。原始来源覆盖和真实公式原子性仍须保留。
无可靠目标的说明可以声明本页 `destination={kind:independent, stream_id}`，不冒充正文接续、脚注或虚构资产。
说明自身的自然段连接与主正文分开解释，不能跨页猜测目标；模型上下文及验收继续遵守单页硬边界。

输出只组合有效成员，不改写来源完整的采用页。已忽略、已移入其他流或已解除关联的
文字不能从资产槽位重新出现；furniture 同样不能重新引入被精修排除的内容。
这些关联属于运行时投影，不增加 PCEX 字段或历史格式兼容分支。

## 单一职责与增量交付

来源捕获固定观测；资产模块统一管理候选、有效关联和槽位组合；段落拼接器处理阅读串、
自然段与跨页尾部；页投影负责顺序及结构约束。后续格式组装不能重新猜测已经采用的段界，
也不能用较弱条件把已分开的段落再次连接。

页任务读取固定初级上下文，不读取邻页精修结果。按局部依赖就绪推进，按序组装已闭合
自然段；不能为 metadata、TOC 或无关页增加全书屏障。必要的跨页段落和脚注依赖可以等待，
条件凑齐后必须及时交付。阶段结果与最终归档成功分开，不能用统计收尾延迟内容回调。

这些约束保护的是可追踪、可恢复和实时交付，不构成所有 PDF 的正确性或成本保证。
JEV 的判断范围见[结构审核](jev-structural-review.md)，管道取舍见[流式设计](pdf-extraction-streaming.md)。
