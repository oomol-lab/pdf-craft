# JEV 结构审核：判断事实，而不是分配精修预算

JEV 的职责是发现初级分析中可以修正的结构错误，让 LLM 把计算用在确实需要的地方。它不是编辑，也不负责决定一本书值得花多少钱。上游质量差时，送修多可能完全合理；正常页大量送修却是审核器的问题。不能只盯着一个总送修比例，把这两种情况混在一起。

本文记录截至 2026-10-31 的研究原则和冻结基线，指导后续上游实验。新基线仍是隔离研究原型，尚未替换包内页级审核；现有 `Refinement.risk_threshold` 也尚未移除。这里确定的后续方向是：**内部校准、固定判断工作点，不向用户提供改变结构对错标准的成本旋钮。**

## 审核对象和证据必须一致

每次只审核当前页，最多使用当前及直接前后两页的初级 OCR 证据。邻页自己的错误不能使当前页失败，邻页精修结果和评分不能进入当前请求。不能让调用时序改变输入，也不能为了审核等待全书。

人工标注同样遵守这个证据范围。不能看了原图或远处章节才得到答案，却要求仅收到局部文本的模型做出相同判断。图像可以用于定位研究中的真实问题；若判别依赖图像上独有的证据，就必须明确模型是否实际收到并理解了它。

原始文字、来源框和来源身份是证据；初级 ownership、OCR 分类和段落连接是待检查的假设。不能把算法自己的结论又当成证明它正确的证据。正文前驱可能被误标脚注遮住，不能只提供算法选好的最后一个块，再要求模型发现前驱选错了。

完整来源不能悄悄截成摘要。摘要适合定位，不能替代被要求审核的文字。要控制请求大小，可以将问题拆成小批，而非删掉决定答案的证据。

## 哪些属于错误

只接受能定位到当前来源块、且已有结构编辑能够修正的问题：

- 主体文字、附属脚注和出版附属物的错误归属。
- 后块 `continues_from_previous` 的错误决定，例如把同一个词硬切，或把独立编号条目接到上一条。
- 脚注开启时，现有定义、印刷标记与正文引用之间的结构关系错误。

作者措辞、错别字、OCR 逐字转录、知识真假、最终目录及标题层级都不属于此审核。不能因为书难、文字多、句子不通或自己更喜欢另一种分段，就要求 LLM 修复。

自然段不是主题。问答、同一事件、因果关系、句号或冒号都不足以单独决定是否连接。一个自然段可以有多个完整句；引文也可以独立排印。整框 bbox 不能证明多行文字首行缩进。证据不足不等于确定错误；在人工评估中保留“不确定”，不要为了改善指标把它改成正常或错误。

审核只看当前页的入向，页尾半句话本身合法。后页如何连接归后页负责，不要求当前页预测未来的决定。正文前驱要找排除附属物后最近的真实正文，不能任意跳到更早、恰好接得上的句子。

### 两种脚注模式共享原则，分别限定能力

关闭脚注时，不检查也不要求生成 citation、索引或 ref。原文保留引用字符合法，成页或章末校释仍可能是主体。第一轮识别出的来源也可能分类错误，不能把 footnote 分类当成不可恢复的删除命令。

开启脚注时，正文与脚注是不同阅读流；已有定义与引用需遵守对应关系。脚注可以包含多个自然段、长引文和无编号续段。只改正带编号的起点，却遗漏其后解释，依然不完整。

两种模式都不能仅凭页底、小字、编号或解释文体排除正文。混合正文与脚注的单块不能靠整块删除来“变干净”。

## 固定标准和内部工作点

业务需要的是稳定的对错判定，不是替用户调整精修预算。同一份初级结果不能因为用户想便宜一些，就从“错误”变成“正确”。下游可以依据判定决定是否精修、保留原结果或采用其他产品策略。

模型仍输出连续分数，因此库内需要固定的判定工作点。这是实现校准，不是主观改变标准；模型或判定协议改变时，应重新验证并记录版本。分数本身不是已校准的现实错误概率。不能用不同候选的原始分数高低直接宣布质量改善。

本轮冻结的是 v2 局部审核原型：入向和归属分别提问，每个具名问题只检查一个决定，每个请求最多四题，整页风险取各题风险最大值。入向使用完整初级证据寻找最近真实前驱；归属使用关闭脚注标准。内部实验工作点固定为未舍入的 `risk >= 0.52`。这不是对生产默认值的修改，也不能未经验证套到脚注开启的另一套协议。

判定必须保存原始响应、未舍入风险和实际布尔决定。浮点差异可能使显示为相同的小数在边界处分到两侧，不能用报表上的四舍五入值重算实际路由。

## 怎样实验才有参考价值

先抓一个具体误判，提出可证伪的解释，做小轮次正反对照；有效后再回到整体样本重复验证。正常结果和只改错一个字段的结果都要测。整个错误页已因其他地方被送修，不代表目标错误已经被识别。

提示只能描述通用结构关系，不能写入测试书籍的原句、人物、页码或答案。由原始坐标、字面标记和像素生成的观测必须说明是候选或测量，不能暗中附上人工正确分类。

每个实验独立保存输入哈希、模型、服务、规则版本、工作点和结果。变更服务之后，不能把旧响应冒充新的重复。网络失败和缺少响应不算放行；不完整的一页不能先按已完成的几题宣布通过。

指标至少同时报告总送修、已知正常误送和已知错误漏送。正常误送占同书全部样本页数的比例，与误送占正常页数的比例不同；分母必须说清楚。抽样窗口不能叫全书，新旧上游的错误标签也不能混用。

上游修复后应重建初级分析，但保持原始 OCR 证据、JEV 规则和内部工作点不变。已修好的旧错误页不能继续算错误，也不能直接算正常来虚增准确率。优先检查少送的页是否真的修好，再检查原本正常的页有没有新损坏。

### 当前证据和边界

相同百页开发样本包括困难书五十页和小说五十页。三轮新 dev 请求共 1,206 次，返回模型均为 `jev-1.14.0`；在复测前冻结上述规则与工作点，期间不调参：

| 轮次 | 总送修 / 100 页 | 已知正常误送 / 38 页 | 选定当前错误漏送 / 18 页 |
| --- | ---: | ---: | ---: |
| 1 | 48 | 0 | 0 |
| 2 | 49 | 0 | 0 |
| 3 | 49 | 0 | 0 |

十八个具体错误锚点也都被识别。但这些是同一批开发书、非独立标注、非穷尽错误集，不能宣布完整样本或新书上零误判。尚有待定页和修复后的旧错误页未全面重审。

已知反例是无编号脚注续文：原错误页可因其他脚注被筛中，但正确排除该续文后，局部审核仍可能要求把它恢复为正文。缩短提示、附原图、整区问题以及实测行距均未稳定解决，失败版本未采用。这个反例须继续保留，不因页级指标漂亮而删除。

## 为什么现在转向上游

在规则固定后继续调阈值，会让前处理与审核器相互追逐，无法判断质量来自哪里。现阶段保持 JEV 不动，让它成为上游迭代的主要验收基线；分数改变就追查对应决定。已知反例和来源守恒仍作独立检查，不把遗漏内容或迎合评分当作改善。

已经离线复现十二页共因：OCR 把竖排文字切成列框，算法却把同一阅读组中的框直接当作独立自然段，没有经过阅读组之间使用的续接判断。这里需要修复“框、阅读组、自然段”的对应，而非继续教 JEV 接受断词。正确方向是先用确定性回归固定机制，再重建同批初级产物，用冻结审核观察错误是否减少，同时保护真实段落、编号、标题、资产、来源身份与流式交付。
