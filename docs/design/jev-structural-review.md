# JEV 结构审核

JEV 审核初级页面分析中可由结构编辑修复的错误，LLM 按需修复。两者分开是为了让
正确页面保留确定性结果，错误页面获得语义修正，而不是为每页固定增加一次 LLM 调用。
送修比例同时取决于上游错误和审核误判，不能单独作为质量指标。

## 审核边界

只判断当前页的来源归属、自然段入向续接，以及开启脚注时的定义和引用关系。作者措辞、
错别字、知识真假、缺失的 OCR 原文和最终 TOC 层级不属于这项结构审核。

原文、来源身份和几何是证据；OCR 分类、初级 ownership 和连接是待审核的结论。
角色问题不能把这些猜测当成正确答案。证据不足不等于确定错误，也不要求模型补造来源。

证据限于当前及直接相邻的初级页，不读取邻页精修结果或 JEV 评分。这样请求不随并发
完成顺序改变，也无需等待全书。只评价邻页错误对当前页决定的影响，不因邻页自身有错
就否决当前页。实际前驱必须明确，不能跳过真实来源寻找另一个恰好能接上的片段。

## 判定原则

- `continues_from_previous` 是入向连接真源；当前页未完的尾句不独立构成错误。
- 同一自然段可以包含多个完整句。语义相关、标点或篇幅不能单独决定合并或拆分。
- 必须连接与允许连接不同。另起段切断必要词语或句法依赖才应否决；已有合段连接了
  独立阅读单元才应否决。不能只因另一种排版同样合理而要求精修。
- 独立段落公式是硬边界，图片和表格可以嵌在自然段中；图注、署名和真实正文需要区别。
- 图片说明使用当前格式的 title/caption，不把 image.content 当作展示文字。

关闭脚注时，不要求生成 citation/ref；原文引用字符可以保留。成页校释、参考文献或
作者括注仍可能属于主阅读内容，不能仅凭编号、小字、页底位置或解释语气删除。

开启脚注时，正文和脚注分别保持阅读流。印刷标记与内部索引不是同一个身份；真实脚注
可以有多个自然段和无编号续文。正文未识别出引用，不代表明确的新注释定义不存在。

## 局部事实与聚合

两种模式分别使用基础审核及按需补充事实。补充检查用于分离容易混淆的事实，例如
“实际前驱是谁”和“是否补齐它的必要成分”，避免一个含混判断替代多个独立条件。

多项事实共同支持一个决定时，取共同成立的证据。容错证明只能降低对应来源、对应测试
的风险，不能豁免其他归属、段界或引用错误。整页按剩余最大风险决定是否调用 LLM。
分数不是经过校准的现实错误概率，也不代表网站整体的精修比例。

`Refinement` 不公开阈值。当前内部工作点在关闭脚注时为风险 0.52，开启时为 0.45；
使用未舍入的通过分数与对应边界比较，恰好位于边界也进入精修。不按配额动态改变判定。

## 模板与执行

提示说明统一使用英文，原始文档证据保留原语言。两种模式、两轮审核共有四个根模板，
入口及共享内容见[模板索引](../../pdf_craft/extractor/chapter/data/README.md)。
模板直接呈现可读提示；Python 负责证据、候选选择、请求组织和评分聚合，不追加提示正文。
提示不能包含测试书籍原句、人物、页码或答案。

四个模板入口不等于四次请求：每轮可以产生多个具名批次，每请求最多四题。基础和补充
请求共用用户的 JEV executor、重试、usage 和请求观察，不另建并发额度。补充请求只等
当前页基础结果，不等其他页，也不能阻塞无关页面的 LLM 或内容流。

每批必须返回全部有效具名分数。缺失或失败不能冒充完整通过，也不能因 JEV 服务故障
自动把页面送去 LLM；按 analysis 错误策略退回初级结果或传播异常。无可审核项不伪造请求。

## 能力边界

结构审核通过不保证 OCR 转录完整、所有结构错误都被发现或后续 LLM 必然修复成功。
不能用删除原文、隐去证据或改变人工标签来改善指标，也不能从定向抽查推断总体准确率。

页处理完成事件报告该阶段的 `refinement_status`；后续章节组装和最终文件成功属于其他
阶段。具体事件契约见[进度说明](../zh-CN/TRANSLATION_PROGRESS.md)。
上游约束见[初级页面分析](upstream-dynamic-repair.md)，并发取舍见[流式设计](pdf-extraction-streaming.md)。
