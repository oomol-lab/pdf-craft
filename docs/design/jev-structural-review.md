# JEV 结构审核

JEV 判断初级分析是否存在可修复的结构错误，LLM 负责按需修复。送修比例同时受
上游错误数量和审核准确性影响，不能单靠降低送修比例衡量审核质量。

## 审核范围

每次只审核当前页，证据限于当前及直接前后两页的初级 OCR 结果。邻页精修结果和
JEV 评分不进入当前请求，避免并发时序改变审核输入，也不为审核等待全书。

审核对象是来源归属、自然段入向续接，以及脚注开启时的定义和引用关系。作者措辞、
错别字、OCR 逐字转录质量、知识真假和最终 TOC 层级不属于结构审核。

原文、来源身份和框是证据；OCR 分类、初级 ownership 和段落连接是待检查的结论。
邻页自身的错误不应导致当前页失败。正文前驱应是排除附属物后最近的真实正文，
不能只取数组最后一项，也不能跳过真实正文去选择更早、恰好能接上的文字。

`continues_from_previous` 是入向连接真源。当前页末尾半句话可以合法存在，后页是否
续接由后页的入向决定；派生的出向标记不能独立触发当前页精修。

## 自然段和归属标准

语义相关不等于属于同一自然段。主题、问答、因果关系、句号或冒号均不能单独决定
合并或拆分。完整词语被硬切是结构错误；多个完整句可以位于同一自然段。多行整框
的边界也不能当作首行缩进的证据。独立段落公式是硬边界，图片和表格可以是段内资产。

关闭脚注时，不要求生成 citation、索引或 ref，正文保留原有引用字符合法。成页或
章末校释仍可能属于主阅读内容，不能仅凭编号、小字、页底位置或解释文体删除。
第一轮 footnote 分类也不是不可恢复的删除命令。混合正文和注释的来源不得整块丢弃正文。

开启脚注时，正文和脚注是不同阅读流，已有定义、印刷标记和引用需要对应。脚注
可以包含多个自然段、长引文及无编号续文。

证据不足不等于确定错误。审核应定位可由现有结构编辑修复的具体决定，不要求模型
补足未提供的文字、推测远处章节或遵守额外的排版偏好。

## 关闭脚注时的局部协议

基础审核逐一判断归属和已有续接。对于另起自然段，词内硬切和必须相连的句法结构
分别提问，避免把完整推导步骤、引文或正常省略误当作必须合段的表达。每请求最多四题。

基础分数齐备后，仅为符合局部条件的来源补充具名事实检查：

- 重叠 OCR 副本：完整文字包含关系只用于筛选；还需确认是否为同一印刷区域的无损冗余。
  完全相同的候选只与更早来源比较，保留至少一个代表。不同位置的印刷重复不是可删除副本。
- 独立注释分节：分别确认分栏阅读顺序中的独立分节及目标的完整归属。目标框若覆盖标题之前
  另一正文块的内部区域，暂不使用这个归属豁免；框重叠本身不直接判定页面错误。
- 作者署名、独立引文和已闭合引语：只证明对应归属、词界或句法边界，不为其他错误背书。
  同栏下方的块不能被当成已经闭合的左侧表达。
- 图片旁文字：分别确认图注角色及独立起读；对完整重放前文的片段，分别确认独立条带布局、
  前文正文来源和完整摘录。插图存在、重复字串或摄影署名单独出现都不能直接决定段界。
- 对话：新话轮和说话人不同是两个事实。只有同时成立才判错接，不能只因引号、姓名或叙述
  接引语就强迫分段；后置署名、同一人继续发言和嵌套引用需要区分。
- 跨页词续接：补足实际前驱词尾的证明只适用于该条已有续接；不能据此放过归属或其他段界错误。

完整文字匹配仅归一 ASCII 排版空白，不删除标点、数学内容或任意 Unicode 字符，也不改写
OCR。所有问题保留同一份局部原始文字与来源身份，不把推测的修复结果送回去冒充证据。

每题分数保留到当前页聚合。基础题的错误风险为 `1 - pass_score`；多项事实必须同时成立时取
各事实分数的最小值作为操作分数。阳性容错证明需达到内部工作点，且只能降低其对应的原始
归属或边界风险。它不能清除独立的对话、图注或其他来源错误。整页取剩余风险的最大值。
这些分数不是经过校准的现实错误概率。

## 运行时与失败

`Refinement` 不暴露评分阈值，调用者通过是否传入 refinement 选择是否启用精校。
关闭脚注时按未舍入的 `risk >= 0.52` 判错；开启脚注保留专用页级协议及工作点 `0.45`。
不根据精修配额、页面数量或成本目标改变结构对错标准。

基础和补充请求共用用户提供的 JEV executor、请求观察、usage 和重试链路。补充请求只等待
当前页自己的基础分数，不读取相邻评分、不等待其他页，也不增加第二套供应商并发额度。
页处理和内容流仍按局部依赖就绪推进，不增加全书屏障。

供应商必须返回每批全部问题的有效具名分数。任一基础或补充批次失败，都不能将已成功的
部分冒充完整审核。依照 analysis 错误策略退回算法结果，或传播异常；没有完整判定不能
伪造审核通过，也不能因供应商故障自动把页面送去 LLM。无可审核文字不伪造请求。

## 验收与边界

人工核验与模型审核使用相同的证据范围。若人工结论依赖原图或更远章节，必须明确模型
是否获得同样证据。缺失首行像素观测时不从整框推断缩进；无法恢复的转录遗漏不直接计作
结构编辑可解决的错误。提示不得包含测试书籍原句、人物、页码或答案。

模型、协议或输入规则改变时，需要重新核对工作点。已审标签绑定其输入与决定，发生变化
后重新核验，不悄悄覆盖旧判断。精修被触发不代表每个结构错误都被发现，更不代表后续
LLM 修复必然成功。插页后真实正文前驱、独立摘录和不完整 OCR 仍有已知边界。
