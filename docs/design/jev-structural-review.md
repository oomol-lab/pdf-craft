# JEV 结构审核

JEV 判断初级分析是否存在可修复的结构错误，LLM 负责按需修复。送修比例同时受
上游错误数量和审核准确性影响，不能单靠降低送修比例衡量审核质量。

## 审核范围

每次只审核当前页，证据限于当前及直接前后两页的初级 OCR 结果。邻页精修结果和
JEV 评分不进入当前请求，避免并发时序改变审核输入，也不为审核等待全书。

审核对象是来源归属、自然段入向续接，以及脚注开启时的定义和引用关系。作者措辞、
错别字、OCR 逐字转录质量、知识真假和最终 TOC 层级不属于结构审核。

原文、来源身份和框是证据；OCR 分类、初级 ownership 和段落连接是待检查的结论。
邻页自身的错误不应导致当前页失败。正文前驱应是排除附属物后最近的真实正文，
不能只取数组最后一项，也不能跳过真实正文去选择更早、恰好能接上的文字。

`continues_from_previous` 是入向连接真源。当前页末尾半句话可以合法存在，后页是否
续接由后页的入向决定；派生的出向标记不能独立触发当前页精修。

## 自然段和归属标准

语义相关不等于属于同一自然段。主题、问答、因果关系、句号或冒号均不能单独决定
合并或拆分。完整词语被硬切是结构错误；多个完整句可以位于同一自然段。多行整框
的边界也不能当作首行缩进的证据。独立段落公式是硬边界，图片和表格可以是段内资产。

必须连接与允许连接不能混为一谈。已有断段在切断必要词语或句法依赖时才违反这项约束；
已有合段在错误连接独立阅读单元时才应被否决。缺少强制语法依赖，不代表已有连接错误；
另一种排版同样可行，也不是要求精修的理由。

关闭脚注时，不要求生成 citation、索引或 ref，正文保留原有引用字符合法。成页或
章末校释仍可能属于主阅读内容，不能仅凭编号、小字、页底位置或解释文体删除。
第一轮 footnote 分类也不是不可恢复的删除命令。混合正文和注释的来源不得整块丢弃正文。

开启脚注时，正文和脚注是不同阅读流，已有定义、印刷标记和引用需要对应。脚注
可以包含多个自然段、长引文及无编号续文。

证据不足不等于确定错误。审核应定位可由现有结构编辑修复的具体决定，不要求模型
补足未提供的文字、推测远处章节或遵守额外的排版偏好。

## 提示模板

JEV 的提示说明统一使用英文；原始文档证据保留原语言。每个独立问题维护为一份可直接
阅读的 Jinja 正文，不使用宏函数库或在模板里拼装 JSON。完整清单见[模板索引](../../pdf_craft/extractor/chapter/data/README.md)。

- [正文归属](../../pdf_craft/extractor/chapter/data/body/ownership.jinja)与[具体续接](../../pdf_craft/extractor/chapter/data/body/concrete_join.jinja)：关闭脚注路线。
- [脚注角色](../../pdf_craft/extractor/chapter/data/footnote/footnote_role.jinja)、[定义](../../pdf_craft/extractor/chapter/data/footnote/definition.jinja)和[引用](../../pdf_craft/extractor/chapter/data/footnote/reference.jinja)：开启脚注路线。
- [词界](../../pdf_craft/extractor/chapter/data/shared/gap_word.jinja)与[句法](../../pdf_craft/extractor/chapter/data/shared/gap_syntax.jinja)：共享问题。

`Instructions`、`True`、`False` 标题只划分供应商需要的字段，不作为提示文字发送。
空行划分指令段落；少量补充范围说明独立存为文字片段。Python 负责选择问题、准备证据、
组织请求和聚合分数。模板随包发布；纯排版迁移应核对完整请求不变，翻译提示说明时需
核对原意与输入结构，并另行验证实际审核效果。

## 关闭脚注时的局部协议

基础审核逐一判断归属和已有续接。对于另起自然段，词内硬切和必须相连的句法结构
分别提问，避免把完整推导步骤、引文或正常省略误当作必须合段的表达。每请求最多四题。

已有续接必须核对算法实际选择的来源，以页号和来源序号定位，并保留完整原文。
识别出前驱是脚注或图注后，不能假装已将它排除，再用更早的正文批准当前连接。
邻页独立的归属错误和当前入向错误需要区分：前者不自动否决当前页，后者把不同印刷
阅读单元接成同一自然段，必须计入当前页。真正连续的脚注或引文片段仍可合法相接。

基础分数齐备后，仅为符合局部条件的来源补充具名事实检查：

- 重叠 OCR 副本：完整文字包含关系只用于筛选；还需确认是否为同一印刷区域的无损冗余。
  完全相同的候选只与更早来源比较，保留至少一个代表。不同位置的印刷重复不是可删除副本。
- 独立注释分节：分别确认分栏阅读顺序中的独立分节及目标的完整归属。目标框若覆盖标题之前
  另一正文块的内部区域，暂不使用这个归属豁免；框重叠本身不直接判定页面错误。
- 作者署名、独立引文和已闭合引语：只证明对应归属、词界或句法边界，不为其他错误背书。
  同栏下方的块不能被当成已经闭合的左侧表达。
- 图片旁文字：分别确认图注角色及独立起读；对完整重放前文的片段，分别确认独立条带布局、
  前文正文来源和完整摘录。插图存在、重复字串或摄影署名单独出现都不能直接决定段界。
- 对话：新话轮和说话人不同是两个事实。只有同时成立才判错接，不能只因引号、姓名或叙述
  接引语就强迫分段；后置署名、同一人继续发言和嵌套引用需要区分。
- 跨页词续接：补足实际前驱词尾的证明只适用于该条已有续接；不能据此放过归属或其他段界错误。
- 页边出版信息：对仍被保留为正文的短页边块，独立确认是否为页码、书眉或章节页脚。
  仅上沿10%或下沿10%中不超过160字符的块进入这项补充核验；位置与长度只决定是否提问，
  不直接判错。必须有出版附属物的正向证据，不能把短标题、署名、练习题、真正注释或
  页底正文当成页脚。空白页上的页脚也不会因此变为正文。
- 无文字页面的痕迹：整页 OCR 文字均不含字母或数字时，独立核验仍被保留的标点块是否
  为非阅读噪点。标点本身不直接判错；有阅读意义的问号、分节符号及数学记号需要保留，
  不能仅因 OCR 给出了大矩形就推断原图印着一个大字符。

完整文字匹配仅归一 ASCII 排版空白，不删除标点、数学内容或任意 Unicode 字符，也不改写
OCR。所有问题保留同一份局部原始文字与来源身份，不把推测的修复结果送回去冒充证据。

每题分数保留到当前页聚合。基础题的错误风险为 `1 - pass_score`；多项事实必须同时成立时取
各事实分数的最小值作为操作分数。阳性容错证明需达到内部工作点，且只能降低其对应的原始
归属或边界风险。它不能清除独立的对话、图注或其他来源错误。整页取剩余风险的最大值。
这些分数不是经过校准的现实错误概率。

关闭脚注时，跨图片页的既有续接还核验算法实际选中的前驱，而不是另找一个文字能接上的
较早段落。前驱是否为独立图片说明/摘录、当前块是否为正文分别提问；两个事实共同成立，
才构成这条连接的独立风险。输入给出来源身份、完整文字、图片与文字框的实测邻接关系，
测量不是角色结论。角色题只保留来源原文、身份和几何，不把初级 ownership 或 OCR 流标签当作答案提示。
正文可以穿过插图，图片说明也可以续页，不能仅因有图片、署名或相同
故事就判错。即使真实正文前驱在窗口外，仍可检查当前连接是否错误接到了窗口内的独立图注，
不必编造窗口外的正文。

已有续接若受到质疑，可单独确认“例题引入—紧随的数学设定”是否属于同一个例题。
证明只放行对应连接，不豁免新编号、新题目、独立标题或其他错误。已闭合引语的证明只判断
左侧话轮及其外部框架是否完整，不能因为当前 OCR 开头缺字就假设左侧仍有未完成成分。
另起自然段的句法受到质疑时，仅在同页、前驱不在同栏更低处时补充核验。先独立确认该
具体前驱确实属于主阅读流，再核对左侧框架是否已经完整，两项事实共同成立才可放行。
邻页最后一个被保留的块可能是误标脚注，不能用它的句法完整为跨页正文断句背书。当前块是描述短语或
独立的变量定义行，不足以将已经完整的左侧句子重新判成未完成。这个证明只降低同一段界的
句法风险，不放过词内硬切、归属或其他来源的错误；真实未完成的条件、动词和介词补语不能
因标点或公式而获得豁免。
明确编号题干中的条件与紧随的求解命令，分别验证是否属于同一题、命令是否补全该条件；
两项事实共同成立才判定错误拆分。不能据此强制合并新题号或独立排列的数学展示行。
这些补充题只属于关闭脚注路线，不改变开启脚注的提示或聚合规则。

## 开启脚注时的局部协议

脚注路线也使用具名小批问题，每请求最多四题。正文段界共享词界与句法的基础定义，
脚注段界、定义起点和正文引用则单独审核，不把两条阅读流强行合并。

归属问题直接询问原始块是否具有某种角色：主阅读内容、真实脚注或出版附属物。
这类请求不展示算法猜测的 ownership、原 OCR 流或 citation 标签，以免审核把待验证的
结论当成支持结论的证据。段界、定义及引用问题仍保留它们实际需要检查的字段。

整块的印刷角色与文字的解释性含义是两件事。作者括注、修订意见、引文和术语解释
可以位于主阅读流；混合正文和括注的来源不能整块改为脚注。真实脚注需要有独立附属流的
局部依据，不能仅因文字“像注释”而确认。连续校注章节中的跨栏续文和长引用仍属于该主流。
反过来，已建立的真实脚注流内可以有多个自然段、独立引文和无标记续文，不要求每块重印编号。

明确的新注释标记即使被初级算法标为无索引续文，也需要独立检查；正文 OCR 缺少
对应引用不等于这个新定义不存在。反之，没有明确起点的真实续文可以保持无索引。

章末校释和参考文献可以属于主阅读流。归属有疑问时，分别验证独立分节和整块成员关系；
分节标题可能在提供的前一页，当前页不必重复标题。检查需遵守实际横排或竖排栏序，
不能把所有解释文字都当成页底脚注。图片旁独立文本与重叠 OCR 副本复用已有的事实检查，
每项证明只作用于它对应的来源，不能掩盖其他归属、引用或段界错误。

误入脚注流的正文残片、独立图名也属于归属审核。残片不完整、来自第二轮 OCR，或
文字与主段重复，都不能单独证明它是真实脚注。反过来，真实长脚注及其跨页续文不因
语法完整、篇幅较长或未重印编号就变成主阅读章节。

对于尚未建立起点的无标记 citation，可从当前或前一页的短原文筛选分节候选，不要求
OCR 先标出 heading；只保留文档顺序在目标之前的最近三个候选。候选不是事实，需分别
证明其独立主阅读分节及目标的完整成员关系，两项均成立才能以主阅读归属否定该来源当前的 citation 决定。
该证明不能清除出版附属物、其他来源或引用关系的独立错误；缺少任一响应不能给出部分结论。

脚注路线对被否决的正文独立引语段界也使用局部证明，候选和聚合遵守该路线自己的
固定工作点。完整引号或前驱冒号只提供检查线索；须确认实际独立发言、朗诵或歌词，
不能把句中引用词、公式或未完成的语法成分当作完整引语。已连接的段界不使用该豁免。
证明只作用于同一来源被否决的词界与句法边界，其他错误保留。

对于前一引语已经闭合的疑点，分别证明其词尾与外部句法框架的完整性；词界证明不能
清除句法错误，反之亦然。被打断的发言只要求话轮结束，不要求其中被放弃的句子完整；
包含它的外部条件句、从句仍须检查。独立变量定义、数学展示或编号练习可以另起，
但普通行文含有公式不代表独立展示，也不能据此豁免词内硬切。

被否决的已有续接可核验“报告框架—同一人的直接发言”关系。冒号与引号只筛选候选，
不证明该关系成立；换人发言、引用术语、独立叙述和已经完整的旧发言不得套用。
所有补充证明只减弱对应来源的对应测试，缺失响应仍不得发布部分结论。

短中文词续接的补充核验把实际前驱关系与字面未完词分开判断，两项取共同成立的证据。
词面吻合不能授权跳过真实的中间正文、图注或署名；也不能豁免同页其他错误。候选只由
已存在且被基础审核否决的连接产生，不从更远的页面搜索匹配词尾。

必要语法续接与词内续接是不同事实：左侧可以已经结束一个词，却仍缺必需的修饰对象、
介词宾语或条件主句。补充核验须同时证明实际最近正文前驱与立即目标确实补足该依赖。
话题相关、两个完整句的可选连接，以及冒号后的独立引语都不构成这种证明。


数值独立展示是版式事实，与引入句能否脱离数值独立成句分开判断。只有纯小数、可靠的
同栏前后正文、居中位置及上下空隙共同成立时才提出该事实问题。证明只涉及指定语法
段界，不能覆盖词内截断、角色错误或其他引用问题。

## 正文中的出版附属物疑点

出版附属物是页面组织的角色，不由文字主题决定。文档教读者如何打印或处理纸张，仍是
正文；出版转页提示说明的是文章本身在哪里续接。主阅读序列中的卷标题也不同于边栏运行
标签。空白页只有页脚时，页脚不会因为成为第一个来源就变成章节开头。

对已保留在 paragraph、又被基础审核怀疑为出版附属物的来源，补充核验其整体是否具有
明确的主阅读位置和功能。原基础请求保持不变；这一正向证明只能降低同一来源的出版
附属物风险，不能清除真实脚注归属、段界、引用或其他来源的错误。无法确认出版附属物
不等于已经证明它是正文；需要独立的主阅读证据。

不把这一保留正文的证明直接用于 citation：即使目录目的页码不是当前页码，将它放在
脚注流也可能仍然错误，不能用局部豁免掩盖另一项错误归属。

## 引用身份与替换位置

引用审核只判断原始印刷标记与内部引用的对应，不评价注释是否在语义上解释了正文，
也不因正文末尾尚未闭合或邻块错误否决当前引用。印刷 mark 与内部 index 可以不同，
XML path 不是字符偏移；没有引用的正文块不必使用本页所有定义。

对已有引用，在不改写原始证据的前提下展示原文到分析文本的字面编辑摘要，并将身份对应
与替换位置拆为具名问题。两项独立汇总，任何明确错误都不能被另一项通过抵消。摘要只是
定位证据，不是正确性证明；格式包装和空白变化不自动等于移动标记。

摘要先裁去相同前后缀，剩余比较区间任一侧超过4096字符时省略摘要及独立位置问题，仍保留
原始结构输入和引用审核。此边界限制本地计算，不删除来源，不生成虚构的通过结果。
若脚注流只有标点、没有具名定义且当前块没有已有引用，不为其生成引用问题；现存引用
即使目标缺失也仍须检查。

## 图片的局部证据

图片的展示文字来自当前格式的 title/caption，不从非展示的 image.content 回退。
当前页及直接邻页均保留图片/表格的位置证据，图片说明不能因为字段迁移或邻页视图只选文字
而漏出审核输入。相邻页资产只是原始局部上下文，不是正文前驱，也不增加页处理的等待范围。
这不改写原始 OCR、PCEX 字段或实际段落，只补齐审核能看到的证据。

## 请求体中的长重复文本

重复字符和连续编号可能来自 OCR，但审核不能先删除它们来获得一个“正常”的输入。
传输视图可把字面重复和连续整数序列无损编码为 `literal_parts`；请求同时说明完整解码规则。
普通文字、来源身份、顺序、坐标和引用位置仍保留。没有引用变化的 analysed_text 副本可省略，
有引用替换时仍保留原文及标记位置。这些压缩只用于 JEV 输入，不改写 OCR XML 或 PCEX。

## 运行时与失败

`Refinement` 不暴露评分阈值，调用者通过是否传入 refinement 选择是否启用精校。
关闭脚注时按未舍入的 `risk >= 0.52` 判错；开启脚注使用局部事实协议及工作点 `0.45`。
不根据精修配额、页面数量或成本目标改变结构对错标准。
边界直接用通过概率与 `1 - threshold` 比较，恰好位于阈值时触发精修；不先将概率取补
再比较浮点风险值，也不将分数舍入到较少位数后判断。

基础和补充请求共用用户提供的 JEV executor、请求观察、usage 和重试链路。补充请求只等待
当前页自己的基础分数，不读取相邻评分、不等待其他页，也不增加第二套供应商并发额度。
页处理和内容流仍按局部依赖就绪推进，不增加全书屏障。

供应商必须返回每批全部问题的有效具名分数。任一基础或补充批次失败，都不能将已成功的
部分冒充完整审核。依照 analysis 错误策略退回算法结果，或传播异常；没有完整判定不能
伪造审核通过，也不能因供应商故障自动把页面送去 LLM。无可审核文字不伪造请求。

## 验收与边界

人工核验与模型审核使用相同的证据范围。若人工结论依赖原图或更远章节，必须明确模型
是否获得同样证据。缺失首行像素观测时不从整框推断缩进；无法恢复的转录遗漏不直接计作
结构编辑可解决的错误。提示不得包含测试书籍原句、人物、页码或答案。

模型、协议或输入规则改变时，需要重新核对工作点。已审标签绑定其输入与决定，发生变化
后重新核验，不悄悄覆盖旧判断。精修被触发不代表每个结构错误都被发现，更不代表后续
LLM 修复必然成功。插页后真实正文前驱、独立摘录和不完整 OCR 仍有已知边界。

验证范围见[关闭脚注验证](../verification/jev-upstream-automatic-analysis.md)和
[开启脚注验证](../verification/jev-footnote-analysis.md)，
通用修复原则见[上游动态修复](upstream-dynamic-repair.md)。
