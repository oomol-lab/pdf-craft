# PDF Craft v2.0.0

PDF Craft 2.0 is a major release that unifies PDF conversion, translation, and
rendering behind the `PDFCraft` API. It adds first-class EPUB translation, translated
PDF output, six OCR backend choices, and a clearer installation model for local and
remote OCR.

## Highlights

### One API for PDF workflows

- Use `PDFCraft` to convert PDFs to Markdown or EPUB, translate content during
  conversion, or create a translated PDF while preserving the source page layout.
- Reuse extracted document data when an advanced workflow needs separate extraction,
  translation, rendering, or PDF patching stages.
- The old top-level `transform_markdown` and `transform_epub` wrappers have been
  removed. Migrate integrations to `PDFCraft.convert_pdf_to_markdown` and
  `PDFCraft.convert_pdf_to_epub`.

### EPUB and PDF translation

- Translate existing EPUB files into a target-language edition or a bilingual edition.
- Choose whether translations replace the original text or are appended for bilingual
  reading.
- Translate scanned PDFs and write translated text back into the matching source PDF.

### OCR that fits your environment

- Choose DeepSeek OCR, DeepSeek OCR 2, or Baidu Unlimited OCR.
- Run OCR locally with a CUDA-capable NVIDIA GPU, or use a vendor backend when remote
  compute is a better fit.
- The default installation supports vendor OCR without installing local model runtime
  dependencies. Install `pdf-craft[local]` only for local OCR.

### More reliable repeat runs

- Add ownership checks and recovery safeguards for OCR and translation caches.
- Add smoke and CLI coverage for the supported OCR backends and conversion routes.
- Reject unsupported DeepSeek OCR 2 local presets early with an actionable error.

## Documentation

- Reworked the English and Chinese READMEs around the common user paths: install,
  convert a PDF, translate PDF or EPUB content, and choose an OCR backend.
- Added Chinese advanced guides for installation, OCR configuration, PDF conversion
  and translation, EPUB translation, API reference, and troubleshooting.
