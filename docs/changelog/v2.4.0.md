# PDF Craft v2.4.0

## What's Changed

### Async-first SDK

- Make `AsyncPDFCraft` and native async component methods the primary execution path, while
  retaining `PDFCraft` as the synchronous compatibility facade.
- Keep blocking OCR, PDF, archive, and rendering libraries in their owned execution domains so
  event-loop callbacks, cancellation, and external model calls remain responsive.

### JEV-assisted footnote refinement

- Add a reversible page-analysis layer between traditional footnote resolution and chapter
  assembly, without changing algorithm-only output.
- Add three explicit footnote tiers: disabled, traditional algorithm, and JEV-routed LLM
  refinement through `FootnoteOptions` and `FootnoteRefinement`.
- Use the official TypeSafe async SDK for bounded-concurrency JEV review, then repair only
  low-confidence pages with constrained JSON and deterministic integrity validation.

### Extraction and PDF output

- Preserve corrected PCEX document metadata when patching translated text back into PDF files.
- Consolidate localized reader and contributor documentation around the async-first API.
