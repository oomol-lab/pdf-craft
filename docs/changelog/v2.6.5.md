# PDF Craft v2.6.5

PDF Craft 2.6.5 adds translation-size previews and operation-scoped resource
reports, so applications can inspect source words before execution and observed
remote consumption after completion, failure or cancellation.

- New `pcex_words_count` and `epub_words_count` read-only queries share the actual
  translation pre-scan and source-word rules. Matching options produce the same
  total as translation's `STARTED.total_words`. Both Craft facades expose methods;
  the async facade keeps parsing outside the event loop.
- New `UsageCollector`, `UsageReport`, `Usage` and `RequestUsage` group observed
  requests and input/output/cache-hit input tokens by original provider object.
  Pass `usage=` to model-calling operations and inspect `usage.report()` without
  changing the operation's existing return type.
- Accepted and discarded consumption are separated as `effective` and `wasted`,
  including transport retries and business validation loops. Missing usage is not
  estimated. Provider prompt cache is distinguished from ordinary input; local
  cache hits do not create external consumption.
- Support LLM, JEV and OCR vendors. OCR counts recognition submissions rather than
  pages, authentication calls or polling. Existing `OCRTokensMetering` is retained.
- See [usage and sizing](../en/USAGE.md) or [中文说明](../zh-CN/USAGE.md) for examples,
  the accounting boundaries, and limitations. PCEX v4 and progress events are unchanged.
