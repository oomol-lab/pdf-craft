# PDF Craft v2.3.1

## What's Changed

### Corrected page-furniture translation

- Add `with_furniture=False` to PCEX and PDF translation. When enabled,
  PDF Craft translates page furniture already present in the PCEX after
  NarrativeFlow, records its coverage, and includes it in the translated PDF.
- Make `ExtractionOptions.includes_furniture=True` the default for direct
  PDF-to-PCEX extraction. This option only retains `furnitures.xml`; it never
  requests furniture translation by itself.
- Keep PDF-to-Markdown, PDF-to-EPUB, and EPUB-to-EPUB free of furniture work,
  because those outputs do not render fixed PDF page furniture.
- Replace the CLI's extraction-only `--furniture` behavior on PDF translation
  with `--with-furniture`, which performs the complete extraction, translation,
  and PDF-patching path.

### Breaking change

- Remove the public `PDFCraft.translate_furnitures()` step. Use
  `PDFCraft.translate_extraction(..., with_furniture=True)` instead.
