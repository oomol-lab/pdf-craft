# PDF Craft v2.2.2

## What's Changed

### Optional OCR book metadata

- Add opt-in front-page OCR metadata extraction for PDF-to-EPUB and reusable `.pcex` workflows.
  A dedicated metadata LLM starts with three raw OCR pages and can inspect up to twelve front pages
  before returning verified bibliographic fields.
- Validate the JSON protocol through the existing repair loop and require page-local OCR evidence for
  every retained field. Invalid responses are repaired in conversation; an exhausted metadata request
  never aborts the document conversion.
- Treat OCR as the authoritative source. Native PDF Info values fill only OCR-missing fields and
  no longer silently become default book title or author metadata.

### PCEX metadata v2

- Upgrade canonical `.pcex` manifests to format v2, preserving original titles, author original names
  and nationalities, publication details, subjects, and rights alongside EPUB-ready core metadata.
- Continue to read v1 `.pcex` archives. EPUB rendering retains its existing mapping for title,
  description, publisher, ISBN, authors, editors, and translators.
