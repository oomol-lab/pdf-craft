# PDF Craft v2.2.1

## What's Changed

### More resilient PDF fill

- Add `ignore_errors` to PDF translation and patching. When enabled, a page whose erase, text, formula, or PDF-composition work raises an exception is retained as its non-interactive visual base while the remaining pages continue to be filled.
- Preserve the normal fail-fast behavior by default. If every page scheduled for fill falls back, PDF Craft now raises `NoUsableFillPagesError` rather than emitting a misleading successful output.
- Keep fallback pages free of the source PDF's selectable text layer and retain the existing Annotation restoration policy.

### Paragraph layout and forced completion

- Refine paragraph-aware fill across irregular and multi-page source boxes. PDF Craft plans virtual line slots before assigning complete wrapped lines to their source boxes, then performs page-local font normalization without moving text between boxes.
- Remove the implicit 12pt ceiling from automatic fitting. Automatic font fitting now searches from a small probe until geometry rejects the next size, while an explicitly configured maximum remains a hard ceiling.
- When valid source geometry still cannot contain all replacement text at the minimum size, write the complete text from the first source box rather than aborting the entire PDF. This is a last-resort visual fallback and may extend beyond normal box or obstacle boundaries.

### Inline-formula semantics

- Add PDF marked-content `ActualText` for vector inline formulas. Readers that support this semantic layer can expose a plain-text form of a rendered formula instead of its implementation glyphs.
- This is not a complete tagged-PDF implementation and does not promise that every PDF reader will copy a formula in the same order as surrounding paragraph text. Disabled or unavailable vector rendering continues to use the readable plain-text fallback.
