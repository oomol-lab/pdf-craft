# PDF Craft v2.0.2

## What's Changed

### Translation API

- Translation events now include completed and total source-character counts for each TOC, metadata, or chapter item, in addition to aggregate scope counts.
- PDF conversion translation uses one explicit `translator` parameter; the former `on_progress`, `steps`, and `TranslationStep` APIs have been removed.
- Translation event reporting is available consistently across EPUB, PDF package, PDF, and PDF-to-Markdown/EPUB translation workflows.

**Full Changelog**: https://github.com/oomol-lab/pdf-craft/compare/v2.0.1...v2.0.2
