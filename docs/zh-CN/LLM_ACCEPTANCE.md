# LLM 验收原则与空白处理

PDF Craft 的 LLM 验收“宪法”：**只要结果没有歧义、能够由算法修复，就直接修复并验收；
不要为没有必要的表面格式标准强迫模型重做、浪费 token。** 信息确实不足或存在多个有意义的
解释时，才要求模型纠正。这是 LLM 操作的一般原则，不允许猜测文字或牺牲最终成果的正确性。

## XML 填充

可信文字来自第一阶段的完整译文；原始 XML 提供身份、结构、样式及空白上下文，不能用原文
替代译文。结构校验通过后，将未改变的非空白字符与完整译文对齐，按共享规则恢复唯一可确定
的普通空白，再采纳结果。句尾多出的排版空格、单个文本槽内部漏掉的词间空格，可以不增加
fill 请求。不同样式槽之间缺少分隔时，需要已有归属或唯一的来源归属；不能唯一判断就重试。
公式仍按既定协议将分隔放在公式恢复不会覆盖的位置。

恢复是事务性的：无法恢复时不修改候选。文字、标点、NBSP 和其他 Unicode 分隔符保持严格，
来源 ID 与所需标签也继续校验。漏译、改字或有歧义的归属继续进入有限重试。本轮不扩展通用的
标点、拼写纠错。

## 共享 HTML/CSS 空白规则

`transformer/whitespace.py` 为 friendly XML、文本分段及译文恢复提供共同规则；block/inline
复用现有 `xml/inline.py` 分类和显式 `display`，不维护第二份标签名单。

| 上下文 | 处理方式 |
| --- | --- |
| `normal`、`nowrap` | 折叠普通空格、Tab 和分段换行；普通段落边缘可清理。 |
| `pre-line` | 折叠空格、Tab，保留换行。 |
| `pre`、`pre-wrap`、`break-spaces` | 保留空格、Tab 和换行。 |
| NBSP 等特殊 Unicode 分隔符 | 保留，不能当普通空白删除或压缩。 |
| 可折叠模式下的纯 block 容器 | 允许增加结构间换行与缩进。 |
| 含 inline 的混合正文 | 不凭空增加分隔；跨槽位统一处理已有空白，不能逐节点 trim 粘词。 |

参与折叠的只有 U+0020、U+0009 与 CR/LF；CRLF/CR 先统一为 LF。CSS Text 3 对普通分段换行
转换留有浏览器自行决定的空间；本库统一转换成空格，不猜测中文上下文并删除换行。
本模块不实现浏览器布局、双向文本定位、自动折行或完整 CSS 层叠，也不宣称 DOM 源字符完全不变。

规则按树继承，支持 HTML `pre`/`textarea` 默认值、内部 `white-space` 提示和内联 `style`。
显式 `xml:space="preserve"` 在该节点作为保留提示，后代继承，也可用显式受支持模式覆盖。
未知显式模式保守保留；不解析外部样式表或选择器。验收依据来源上下文，不相信模型自行更改的
样式。模板中的临时上下文提示在采纳时由来源属性替换。

friendly XML 压缩已有普通空白、排版纯 block 容器；block 内部的混合正文不属于可随意删除的
缩进。保留空白上下文维持原文；`br` 等显式结构节点继续保留，不能当空白删掉。

核验依据：[CSS Text 3 white-space](https://www.w3.org/TR/css-text-3/#white-space-property)、
[空白处理规则](https://www.w3.org/TR/css-text-3/#white-space-processing)、
[HTML 默认渲染规则](https://html.spec.whatwg.org/multipage/rendering.html)。没有解析外部样式或
不支持的布局行为时，不承诺完整浏览器等价性。

来源上下文与最终属性采纳共用 ID、标签及同标签出现顺序的匹配规则，覆盖无 ID 的不同标签
重排；无法匹配来源时拒绝候选。pre 节点不会把父级拥有的 normal tail 也变成受保护空白；
空白按实际字段归属分类，已知普通分隔不能为了通过比较而移入保留空白的槽位。

缺失的首尾空白不能自动当成普通段落 padding。即使来源和候选都没有现成的边缘空白，
也要按可能承载它的来源 text/tail 判断保留模式。单个受保护字段可以从已知译文精确补回
首尾空白；混合边界存在多个可能归属时应要求澄清，不能静默删除或猜测样式归属。
这里是从已知译文恢复内容，并不表示 CSS 允许折叠受保护空白。

空白归属在标准化和重建之前统一确定。唯一来源 owner 优先于模型的放置位置：即使拼接文字
相同，从 pre 移到普通父节点（或反方向）的空白也要归还该槽位。单个文本字段内部的已知
空格、制表符和换行可按该字段模式直接恢复，无需额外 fill 请求；受保护空白须精确恢复，
不是归一化掉。多个受保护 owner 无法唯一分配时，仍要求模型澄清。
