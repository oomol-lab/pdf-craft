# JEV 部分精修：成本工作点与边界

默认 `risk_threshold=0.45` 保存的是部分精修方案。它不保证每个错误页都进入 LLM，
也不保证任意网站都具有相同的精修比例。调用者仍可显式选择其他阈值。
路由条件为 `1 - pass_probability >= risk_threshold`；分数不是校准后的错误概率。

## 当前验收目标：全书额外误送不超过 5%

后续研究以“本来正常、却被送去 LLM 精修的页数 / 同一本书总页数 ≤ 5%”约束额外消耗，
在此约束下尽可能捕获真实错误。错误本来就多的书可以有较高总精修率；不再以总精修率
10%–15% 淘汰候选。误送比例的分母不是正常页数量，也不是已送修页数量。
前文的 10%–15% 是历史实验约束，保留用于解释当时的取舍。

对现有关闭脚注的局部评分原型，使用保存的未舍入分数复算：

| 研究阈值 | 三轮总送修 / 100 页 | 三轮已知正常页误送 / 100 页 |
| --- | --- | --- |
| 0.50 | 45、45、42 | 0、0、0 |
| 0.40 | 50、50、51 | 2、2、2 |

0.40 时，各轮误送均为小说样本 1/50（2%）、拉康样本 1/24（约 4.2%）、
抱朴子样本 0/26（0%）。这避免用混合样本掩盖单本书的已知误送，但分母仍是各书
抽取的窗口，不是全书已经测过的页数。0.35 在拉康样本两轮误送 2/24，超过 5%，
所以不能仅因百页合计误送 2%–3% 就认定符合逐书要求。

这些是**已确认正常页的额外误送比例**，不是完整误送率的上界：17 个待定页中，
0.40 每轮会送修 8–9 页；此外，前处理修复后的旧错误页没有重新完整审核。
其中若已有正常页，实际额外误送必须计入。候选在新标准下值得继续推进，但尚不能宣告
完整样本或全书通过。0.40 是现有数据上的事后工作点，未修改生产默认值。

下一步先复核被选中的待定页与修复后的旧错误页，再在未参与调优的书籍上核验。
通用实验题目模板见[局部评分候选](jev-focused-review-candidate.json)；它只保存通用规则，
不包含原书文字或具体测试答案。十三组对照验证局部判别，不等于全页精修成功率。

## 判定标准

JEV 与标注者最多使用当前页及直接前后页，只审核当前页可编辑的结构决定：
正文/脚注/排除归属、自然段入向续接，以及脚注开启时已有定义和引用的对应。
作者表达、错别字、OCR 逐字质量、最终 TOC 和标题层级不属于此审核。

语义承接、问答、换说话人、句号或冒号本身不能决定是否同一自然段。
不能把整框 bbox 当成多行文字首行缩进的证据，也不能以邻页自身错误否决当前页。
证据不足项单列不确定，不冒充正常页或必修错误。
两套 rubric 分别描述脚注开启/关闭职责；例子只描述通用结构关系，不提供书中原句、
人物或具体测试题答案。

## 关闭脚注模式的研究工作点

缓存样本为 50 页困难书（拉康相关著作 24 页、抱朴子 26 页）及边城小说 50 页。
暂定标签共 45 个明确错误、38 个正常、17 个不确定；同一助手非独立标注。
复核时将 12 个证据不足的旧错误标签改成不确定，没有改成正常来降低误报。

候选通过单页小轮次修改，再回到完整样本检查。在固定问题与阈值下重复评分九轮。下表是原实验按**舍入后的风险分数**
计算的历史结果，不等于当前代码的实际路由；浮点边界修正说明见下文：

| 指标 | 旧 v8 基线，阈值 0.51 | 本轮候选，阈值 0.45 |
| --- | ---: | ---: |
| 平均路由比例 | 13.2% | 14.1% |
| 单轮路由范围 | 11%–15% | 11%–16% |
| 每轮正常页误送 | 0/38 | 0/38 |
| 平均明确错误召回 | 26.7% | 31.4% |
| 小说平均路由比例 | 7.8% | 4.2% |
| 困难书平均路由比例 | 18.7% | 24.0% |

阈值 0.45 在第 7–9 轮前锁定；后三轮路由分别为 16%、12%、14%，合计 14%。
九轮是相同页面的重复，验证的是评分波动，不是未见书籍上的泛化。
等权研究混合不是网站流量分布，表中比例不能外推为全站保证。
观察到 0/38 正常误送也不代表真实误报概率为零。

按原报表，候选增加了对高置信困难书错误的选择，减少了小说路由，也放过更多小说结构错误；
它并非所有书籍和预算区间都优于旧版。不确定项也可能需要修复，不能将旧版路由的
不确定项计作已知浪费。不同候选的阈值不同，不直接比较分数绝对大小。

这批样本有 45% 暂定错误。若精修预算仅为全部页数的 15%，即使所有调用都命中，
错误召回也至多为三分之一。希望同时达到 80% 错误召回与 15% 精修率，需要更低的
实际错误基数；这里的算术界限不能通过修改 prompt 消除。

## 浮点边界与实际路由复核

实际代码比较 `risk = 1 - pass_probability; risk >= risk_threshold`，不会先舍入。
例如供应商返回 `0.55` 时，Python 得到的风险略小于 `0.45`，实际不会送修；
原实验的 `round(risk, 12)` 后比较却会计入。旧报告没有区分这两个口径，
不能据其声称实际错误召回由 26.7% 提升到 31.4%。本轮未改变运行时阈值语义。

依保存的原始 pass 分数（小说）及有限精度风险记录（困难书）重建，local30 九轮
实际送修约为 14、10、12、11、10、12、14、11、11 页，平均 11.7%；
旧标签下召回约为 25.9%，不是 31.4%。困难书缺少原始 pass 精度，重建结果应与
新实验直接保存的运行时决定区别对待。旧 v8 的本次边界重建没有改变历史计数。
后续研究同时保存原始 pass、未舍入 risk、实际 routed、完整请求哈希，不能用显示值重算路由。

## 确定性前处理修复后的继续实验

继续逐例调查找到三处可复现的前处理错误：引号结束符的异常 Python 字面量、
编号条目被逗号/连字符续接规则抢先合并，以及空 OCR 文字框遮蔽真正的文字前驱。
修复只在已有几何候选内处理边界，不采用“所有引号都断段”的规则；引号术语、
逗号后引语归属语及未闭合引文仍可续接。空文字框保留原身份、原文与 bbox，
标为 ignored，不再生成幽灵段落/脚注；空白整页仍保持原有段落边界。

同一百页中保留所有来源身份、原始文字和框，18 页共 44 条结构决定发生变化。
修复后重新调用 JEV 三轮，实际送修均为 10/100 页；对应冻结基线三轮为
13、10、10 页。正常页仍未送修。旧标签没有为这些修复重新制作，
因此这些数字只说明路由消耗，不能作为修复成功率或剩余错误召回率。

1362 项单元测试通过；citation 三页在脚注开、关两种模式均完成真实 OCR、
JEV/LLM、翻译和 PDF 回填。逐页对照原图，未观察到历史脚注重复或整行重叠；
关闭脚注时保留原注释图像，未重新混入译文正文。该三页验证不能替代更广泛的准确率评估。

竖排几何、逐接缝 JEV 判定及简化提示仍属于隔离研究，未纳入包实现。
部分旧标签仅因引入引文后的独立排印而判错，业务验收边界尚需明确；
未因此修改标签，也未将较低路由比例冒充较高准确率。

## 局部评分与整页汇总的差异（隔离原型）

继续实验将一个问题限定为一个现有入向决定，每个请求最多打包四个具名问题。
两种方向的判定都写清楚“当前正在续接”或“当前正在另起段”，保留完整三页原始文字，
消除摘要重复带来的输入膨胀。只审核入向，不审核归属、citation 或 ref，不自动修改页面。

十三组选定的单字段正反对照，包括新增的八组跨页词组、独立编号和标题，
在阈值 0.50 下三轮都能区分正确与人为改错的版本。这说明整页评分的漏判不能直接
等同于模型无法理解局部结构；但选定对照不是全页修复率或独立书籍验证。

完整百页共 96 页有可检查接缝，每轮 657 个接缝、201 个成功请求。锁定阈值 0.50
后，三轮送修分别为 45、45、42 页，38 个暂定正常页均未送修；送修的旧错误标签页
分别为 38、38、35 页。旧标签早于前处理修复，不能将这些数字写成残余错误召回率。
若将阈值提高到 0.88，三轮送修为 14、12、13 页，覆盖旧错误页 11、10、11 页。
它仍未在 10%–15% 预算下接近 80% 覆盖，故未采用为默认方案。

不能据此改为按几何一律保留 OCR 段界。一个三框反例已证明，该原型会把原本正确
续接到较窄下方框的未完句拆开。旧小说 25 个示例接缝中，9 个已被窄修复纠正；
剩余 6 个引出引文、8 个引文后的叙述、2 个其他情形。是否强制保持这些段落的原书
排印边界，尚需明确验收口径。标签没有因此重写，原型也没有进入包实现。

## 脚注开启模式

另有 32 页客户缓存（11 个明确错误、3 个正常、18 个不确定）及 citation 三页。
清理后的 rubric 在风险阈值 0.51 的三轮检查中均路由 11/11 明确错误，未误送三个
正常页，分别额外路由 0、1、0 个不确定页；citation 三页各轮均超过该阈值。
这不足以证明相较旧版取得广泛提升，也不能把开启模式的 0.51 结果套到默认 0.45。
两套 prompt 的工作点应分别评估，显式阈值保持可配置。

## 经验与未完成项

- 先检查评分标签与模型是否使用同一份证据，再将分数重叠归咎于模型能力。
- 单独检查归属和续接有助于定位混淆；本轮主要困难在“语义相关”与“自然段相同”的区别。
- 局部改善必须回到完整样本。短提示、英文提示、改问题名、删部分输入字段等候选，
  均未产生可靠的全面优势；一次局部高分不能作为采用理由。
- 以额外误送占同书总页数不超过 5% 为当前约束，再尽可能减少真实漏判；不再强行限制总精修率。
- 研究只验证了 JEV 评分与路由，没有验证本轮 LLM 实际修复成功率。
- 后续需要独立复核标签、按真实网站书籍构成评估，以及减少确定性初级算法制造的错误。
  独立引文的段落验收口径、真正的竖排栏间续接及评分区分能力仍需继续调查。

复算摘要与逐轮计数见[研究数据](jev-partial-refinement.json)。原始 PDF、用户内容、
临时产物、凭据与完整研究输出不纳入仓库。
