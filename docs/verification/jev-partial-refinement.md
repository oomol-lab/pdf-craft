# JEV 部分精修：成本工作点与边界

默认 `risk_threshold=0.45` 保存的是部分精修方案。它不保证每个错误页都进入 LLM，
也不保证任意网站都具有相同的精修比例。调用者仍可显式选择其他阈值。
路由条件为 `1 - pass_probability >= risk_threshold`；分数不是校准后的错误概率。

## 判定标准

JEV 与标注者最多使用当前页及直接前后页，只审核当前页可编辑的结构决定：
正文/脚注/排除归属、自然段入向续接，以及脚注开启时已有定义和引用的对应。
作者表达、错别字、OCR 逐字质量、最终 TOC 和标题层级不属于此审核。

语义承接、问答、换说话人、句号或冒号本身不能决定是否同一自然段。
不能把整框 bbox 当成多行文字首行缩进的证据，也不能以邻页自身错误否决当前页。
证据不足项单列不确定，不冒充正常页或必修错误。
两套 rubric 分别描述脚注开启/关闭职责；例子只描述通用结构关系，不提供书中原句、
人物或具体测试题答案。

## 关闭脚注模式的研究工作点

缓存样本为 50 页困难书（拉康相关著作 24 页、抱朴子 26 页）及边城小说 50 页。
暂定标签共 45 个明确错误、38 个正常、17 个不确定；同一助手非独立标注。
复核时将 12 个证据不足的旧错误标签改成不确定，没有改成正常来降低误报。

候选通过单页小轮次修改，再回到完整样本检查。在固定问题与阈值下重复评分九轮：

| 指标 | 旧 v8 基线，阈值 0.51 | 本轮候选，阈值 0.45 |
| --- | ---: | ---: |
| 平均路由比例 | 13.2% | 14.1% |
| 单轮路由范围 | 11%–15% | 11%–16% |
| 每轮正常页误送 | 0/38 | 0/38 |
| 平均明确错误召回 | 26.7% | 31.4% |
| 小说平均路由比例 | 7.8% | 4.2% |
| 困难书平均路由比例 | 18.7% | 24.0% |

阈值 0.45 在第 7–9 轮前锁定；后三轮路由分别为 16%、12%、14%，合计 14%。
九轮是相同页面的重复，验证的是评分波动，不是未见书籍上的泛化。
等权研究混合不是网站流量分布，表中比例不能外推为全站保证。
观察到 0/38 正常误送也不代表真实误报概率为零。

候选增加了对高置信困难书错误的选择，减少了小说路由，也放过更多小说结构错误；
它并非所有书籍和预算区间都优于旧版。不确定项也可能需要修复，不能将旧版路由的
不确定项计作已知浪费。不同候选的阈值不同，不直接比较分数绝对大小。

这批样本有 45% 暂定错误。若精修预算仅为全部页数的 15%，即使所有调用都命中，
错误召回也至多为三分之一。希望同时达到 80% 错误召回与 15% 精修率，需要更低的
实际错误基数；这里的算术界限不能通过修改 prompt 消除。

## 脚注开启模式

另有 32 页客户缓存（11 个明确错误、3 个正常、18 个不确定）及 citation 三页。
清理后的 rubric 在风险阈值 0.51 的三轮检查中均路由 11/11 明确错误，未误送三个
正常页，分别额外路由 0、1、0 个不确定页；citation 三页各轮均超过该阈值。
这不足以证明相较旧版取得广泛提升，也不能把开启模式的 0.51 结果套到默认 0.45。
两套 prompt 的工作点应分别评估，显式阈值保持可配置。

## 经验与未完成项

- 先检查评分标签与模型是否使用同一份证据，再将分数重叠归咎于模型能力。
- 单独检查归属和续接有助于定位混淆；本轮主要困难在“语义相关”与“自然段相同”的区别。
- 局部改善必须回到完整样本。短提示、英文提示、改问题名、删部分输入字段等候选，
  均未产生可靠的全面优势；一次局部高分不能作为采用理由。
- 不直接优化“所有旧标签零漏判”。优先守住业务预算，再比较该预算内捕获哪些错误。
- 研究只验证了 JEV 评分与路由，没有验证本轮 LLM 实际修复成功率。
- 后续需要独立复核标签、按真实网站书籍构成评估，以及减少确定性初级算法制造的错误。
  尤其是独立对话合并和引号终止符问题，仍应单独调查与回归。

复算摘要与逐轮计数见[研究数据](jev-partial-refinement.json)。原始 PDF、用户内容、
临时产物、凭据与完整研究输出不纳入仓库。
