# 开启脚注时的结构分析验证

本验证使用固定的双轮 OCR、开启脚注的初级页面处理和官方 `jev-1.14.0` 局部审核协议。
比较审核协议时固定初级页面结构；审核协议区分整块来源的印刷角色与文字的解释性含义，内部工作点为
`risk >= 0.45`。边界在通过概率口径直接比较，不因取补的浮点误差放过恰好位于阈值的页面。
评分集为连续书籍片段共487页，其中475页是不同来源的主集，12页为同源原生 PDF 对照。

## 结果与执行范围

| 结果 | 全部487页 | 主集475页 |
| --- | ---: | ---: |
| 建议精修 | 133（27.31%） | 125（26.32%） |
| 审核通过 | 331 | 329 |
| 无可审核项 | 23 | 21 |
| 技术失败 | 0 | 0 |

基础和补充共3,876个具名请求，每批最多四题。精确相同的请求可复用已有真实响应，
不能把重放计作新调用或独立重复实验。长字面重复使用可逆传输编码；样本中曾超过供应商
输入额度的九个页面均能取得完整结果。

没有新增 OCR、执行 LLM 修复、翻译或 PDF 回填。本表衡量当前协议建议精修的页面数量，
不是实际修复成功率，也不是网站整体费用估计。关闭脚注使用另一套输入与审核协议，
不能直接比较两者的人工准确率。

## 排除正文与脚注混淆后的送修比例

逐页结合原图、原始两轮 OCR 文字和来源框，404页未发现正文/脚注流混淆，38页确认
存在混淆，45页因文字无法对应原图等原因暂不能确认。这个核验只涉及流的归属，
不等于确认 OCR 全文准确、内容完整或其他结构决定正确。

在这404页中，当前65页建议精修，占16.09%；去掉配对原生对照后，主集对应为
61/396，占15.40%。此分母包含无可审核项的页面。页眉页码等其他角色问题、
段落续接错误和审核误判仍需分别核验，不能把这个比例称为 JEV 的误送率。

45页未确认案例不进入上述分母，也不当作正常页。确认混淆的38页中仍有3页未送修，
不能因为排除它们而掩盖漏送。全部标签与输入证据绑定，不外推网站的文体权重或成本。

## 归属判定的针对性核验

在归属核验所用的固定上游、模型和工作点下，采用相同边界规则重放原协议，建议精修
为193页；归属改进后为176页。该对照不包含页边代码排除及独立引语证明；这是审核触发数量的对照，
不能直接解释成实际修复页数。

| 已人工核验的来源事实 | 原协议误判数 | 当前协议误判数 |
| --- | ---: | ---: |
| 20个主阅读文字块被判为脚注 | 18 | 0 |
| 7个真实脚注文字块未判为脚注 | 1 | 1 |

这些是针对性开发样本，判断只涉及来源归属，不是随机抽样或整页正确性标签，不能外推为
487页的整体误报率、漏报率。7个真实脚注块分属两张已知错误页，两页均仍触发精修；其中
一个无编号续段尚未独立识别，不能宣称逐块召回完整。使用全新角色请求重复核验时，上表
结论保持一致，但其他临界页仍可在工作点两侧波动。

## 通过页的新增核验

按书籍确定性抽取20张此前未核验的通过页，每本最多两张。逐页对照原图和固定的
三页结构输入，发现4张存在可由归属编辑修复的错误：正文残片、图名或语言页脚误入
脚注流。当前协议将其中3张送修，仍漏掉1张短图名；其余16张未观察到结构错误，
当前均保持通过。这个按书籍分层的开发样本不是总体随机样本，不能用4/20或1/20
代表全书的真实错误率或漏判率。

补充的独立分节判断不依赖 OCR 已将标题标成 heading。对无明确起点的来源，短原文
只是候选，仍须分别确认独立分节和整块成员关系；普通句子或编号不能直接充当证明。
误入脚注的窄正文残片和独立图名也不因其被标为 citation 而合法。

全新请求重复核验中，两张正文残片的新增命中保持，语言页脚的分数仍靠近工作点，
短图名仍漏判。独立的定义、引用评分也会波动，不能将一次通过当作稳定无误的证明。
送修增加可能来自补获真实漏判；同样不能只凭触发数增加就认定质量提高。

## 引用对应的针对性核验

核验了6个曾仅因引用判断被送修的页面，未找到足以否决相应引用映射的具体证据。
引用审核需区分印刷 mark、内部 index 和 XML path，不得以正文未完、注释主题或其他块的
问题否决当前对应，也不要求每块正文都引用本页脚注。章末注释或缺少对应定义的标记
不强行关联；OCR 漏掉的定义文字不能凭空恢复。

当前协议不再因这6项送修。其中5项仍有可审核问题，按实际生产批次分别进行了3次
全新请求，15个有效结果均通过；另1页的无索引脚注流只有标点，没有真实定义或已有引用，
因此不产生引用问题。这些是已选定的开发案例，不代表总体误送率。

另以同一正常引用构造错目标、漏映射和替换移位三类对照，各进行3次全新请求，9个错误
结果均被拦截；正常对照的3次请求均通过。人工构造对照验证的是具体机制，不能代替真实
错误页的召回率，也不保证供应商未来评分稳定。

## 正文与出版附属物的局部核验

在出版附属物触发来源的定向核验中，确认了两处卷标题和一处说明书操作步骤属于主阅读内容，
却被判成了出版附属物。当前协议为这类已保留正文补充主阅读位置证明；三个误判来源均得到
纠正。只有一页因此解除送修，其余两页仍有独立错误，继续送修。

三个来源各进行3次全新证明请求，9次均取得主阅读证明；另一个真实页脚来源的3次请求
均未取得该证明。它们仅是针对性开发案例，不能据此估计整套样本的误送率或漏判率。
冻结的原有请求与评分继续保留，新增证明只改变同一来源的出版附属物风险。

目录条目的目的页码仍有被误判为当前页码的情况；其错误 citation 归属不能因另一项判断
减弱而被直接放行。语言页脚的评分也仍会波动，这些限制不由本次正文位置证明消除。

## 独立引语与朗诵的段界核验

正文段界被基础审核否决时，可补充核验完整独立引语；说话或朗诵提示后的冒号仅用于
筛选候选，不能证明后面的文字一定可以独立成段。未加外层引号的歌词、诗句仍需证明其
实际独立表达功能，句中引用词、数学表达式和必须补足的句法成分不适用此证明。

固定487页中新增7个小批请求，原有请求逐项不变。三张经原图确认合法分段的页面因此
解除送修；另有三张获得局部引语证明的页面仍存在其他风险，继续送修。证明只减弱同一
来源被否决的词界、句法边界风险，不改变归属、引用或其他来源的判断。缺少补充响应时
不能发布部分通过结论。三张改善页各补做3次全新事实核验，9个整页重算结果均保持通过；
其余基础判断仍复用相同请求的响应，不能将它们称为9次完整端到端重测。

独立合成对照中，完整发言和未加引号的独立歌词各进行3次新请求，均取得证明；句中
引用词与数学表达式各3次均未取得证明。这12次请求用于核验具体机制，不混入书籍质量
分母，也不能替代完整语料的独立重复评估。

## 续接与数学表达的局部核验

对于被否决的正文段界，分别检查前一引语的词尾、外部句法框架是否已经完整；两种证明
不能互相代替。引语被打断时，所说的话可以有意未完，但包含它的外部条件句仍不能被
截断。对于独立变量定义、数学展示和编号练习，须确认实际独立单元功能；普通行文中的
公式、温度单位片段和仍缺主句的条件不能套用这个豁免。

对于被否决的已有续接，直接发言证明只允许把同一报告框架与它所引出的原话连接。
引号、冒号只是候选线索；另一个人的发言、已经完成的原话和引用术语不能据此放行。
该证明只改变这个已有续接，不批准另起段落或其他来源的决定。

固定上游、工作点和此前全部评分后，新增15个请求纠正5张页面的整页误送，其余页面
的整页结果不变。改善页均对照原图确认，各进行了3次全新局部事实核验，15个重算结果
均保持通过；其余基底评分未重测。这些针对性开发样本不能估计整套语料的误送率或漏送率。

独立合成对照包括完整报告框架、被打断的发言、未完成的外部条件、独立变量定义、
编号练习、行内公式补语、同一人的直接发言、换人发言及引用术语。12组情形各3次
新请求，36次结果均在固定工作点符合预期；不混入真实书籍的质量分母。

复现对照必须锁定请求及其对应的基底响应。共享缓存中后续新请求产生的分数不能覆盖
对照的旧评分；请求完全相同也不表示供应商的多次响应一定相同。

## 上游机制与证据

- 句末扁平数字的配对识别兼容结束引号内外两种句号位置，仍要求唯一正文位置及匹配定义；
  缩写、版本、小数、代码和重复候选不因此放宽。固定样本只改变一页，原图确认其引号外
  句号后的数字对应真实注释，恢复后通过冻结的 JEV。
- 已知圈号、星号的 Markdown 转义和行内公式包装不改变其定义身份；有对应定义的正文
  标记采用同一识别规则。普通数字定义需要本页已有明确上标或唯一句末引用候选；
  重复候选、缩写、数学常数、小数和代码不提供推断依据。
- 页边数字须满足局部条件：正文栏外、充分的正文带尺度、无资产重叠、未被正文或引用提及。
  横排还需位于全部文字下方；侧边页码需有占主要文字量的实测竖排列证据。
  居中页码还需满足单行数字尺度、中轴对齐和至少1.5个数字框高度的正文间隔。
  原文、框和身份保留为可恢复的排除。被本规则选中的97个来源已查看
  原图：96个是印刷页码，另1个是被 OCR 误读为数字的裁切标记。页码证据主要集中在小说，
  不能据此外推其他文体。
- 短页边代码需要足量正文、整个框位于正文栏外侧，以及与所有正文资产的充分下方空隙；
  引用标记、同名正文、其他注释解释等情况保留给审核。固定样本中4个新增候选均由原图
  确认为页脚代码；原文、框和来源身份全部保留。纠正后4页均通过冻结的审核协议。
- 页码、章号与短章名组合的页脚，需同时符合受限语法、充足正文带、所有正文资产下方
  的空隙和左右页边位置。正文引用、其他真实注释、普通解释句和稀疏页面均阻止推断。
  当前支持英语、法语、德语、西班牙语和意大利语的章标签，不匹配具体书名或供应商名称。
  固定样本中7个候选均经原图确认为页脚，原文、位置、身份保留；纠正后7页通过冻结 JEV。
- 窗口内已知脚注起点的别名使用未修改的初级身份快照。规范化前页不能使后页丢失起点；
  窗口外未知起点仍保持未决，不增加全书等待。

页边来源级视觉核验只确认这97个数字及4个代码排除决定，不等于逐页核验整本书。JEV 校准时累计人工核验的
61页标签绑定其当时的输入与结构决定，不能直接沿用为更新后上游的准确率分母。当前不报告
全部487页的人工误送率或漏送率。

关闭脚注路线的487页基础审核请求与固定的改动前版本逐字相同。确定性测试覆盖两条初级
投影和无精修增量解析、跨页定义、原始来源保留、年份与正文数字反例、资产标签及未知候选。

## 缩进段界的几何核验

单行左侧缩进由邻近同栏宽正文建立时，不要求该行右端再额外缩进；长行可以到达右栏边。
句末标点后附加的破折号也不能使已有缩进证据失效；没有完成标点的词或句子不因此被截断。
单行估计只在没有实测缩进时启用，已有实测对齐仍优先；句末破折号处理也适用于
实测缩进明确的段界。

固定487页只改变3处正文入向段界。原图确认三处均为独立自然段，其中两页解除送修，
另一页仍保留独立错误。原文、来源框和身份全部保留；关闭脚注投影也只受同样的3处
正文段界影响，包含邻页只读上下文后共9个窗口输入变化。这个对照没有重测关闭脚注
路线的整体供应商评分。

含 LaTeX 的单行不按源码字数估算字宽。两个附近普通单行的框高一致时可提供行高
参照；只有一个参照时，必须紧邻、间距更短且高度范围更窄。已测得的首行对齐不可被
这类估计覆盖，跨栏、不一致字号和疑似多行保持未知。固定样本只改变3张教材页的段界，
原图确认均为独立数学陈述，3页均通过冻结 JEV。相对开启该估计前的共享算法，关闭脚注
路线也只有同样3张目标及其邻页窗口变化，未由此估计该路线的整套准确率。

## 剩余边界

送修比例仍较高。运行页眉页脚、无编号续文、单个 OCR 框容纳多条注释及图片旁独立文本
仍可能需要语义判断；JEV 分数也有波动。不能通过删除待审核文字、放宽结构要求或改变阈值
降低统计值，建议精修也不等于后续 LLM 已经能够修好该页。

审核通过不证明相对原图的内容完整性。来源核验中存在原图有注释、两轮 OCR 均未保留该
注释文字的页面；恢复其余已识别引用后，局部结构审核仍可能通过。缺失文字不在结构输入中，
不能将这种通过计作整页修复成功，也不能仅靠结构审核测量 OCR 漏字、漏块的比例。

反向也存在边界：结构审核可能把正文内的作者括注或连续排版的校注正文误判为页下注释。
来源核验已确认这类归属误判；不能为了降低送修数而将正确正文改入脚注流。

原图、完整请求和响应、输入指纹、逐来源核验与研究笔记保存在私有 worktree 的忽略目录，
不随包发布。输入或协议改变后，旧模型响应与人工判断不能冒充新输入的验收结果。

规则说明见[JEV 结构审核](../design/jev-structural-review.md)和
[上游动态修复](../design/upstream-dynamic-repair.md)。

## 局部页边与词续接证据

无竖排列观测的横排侧页码，仍需独立满足单个短数字、栏外间隔、足量正文、相近字面尺度、
非首行列表对齐和无引用等条件。字面尺度仅是软提示，不单独决定归属。竖排两至三个汉字
数字可由自身堆叠比例提供方向证据，但还须位于足量中文正文外侧下半部，且无正文同号或引用。
本样本新增三个阿拉伯侧页码和一个汉字侧页码均由原图确认。

只有一张充足表格的页面，可用表格行数、远大于行高的下方空白与外缘对齐识别孤立短代码。
近处图注、稀疏表格、罗马数字、表内同名及真实注释标记仍交给审核。三个新增候选经原图
确认均为页脚代码，未删除表格或代码来源。

被基础审核否决的短中文词续接，可分别核验“确为紧邻正文前驱”与“字面确为未完词”。
两项均成立才支持现有连接；不能跨过保留文字寻找更早的匹配词尾。这项核验只改变指定连接，
不豁免其他段界、角色或引用错误。正例、完整句负例及跳过真实中间段的负例均有独立供应商响应。

相对上述局部规则加入前，487页的原文、框与来源身份均保留；关闭脚注的487个审核窗口
保持相同。新增规则没有增加邻页评分或全书等待。七页解除送修，不等于完整人工准确率验证。


显式的数字加句点、右括号或成对括号可建立脚注定义，不要求正文引用号也被 OCR 保留下来。
定义的印刷标记和页内索引分开保存；缺失的正文引用不补造。裸数字仍需匹配证据，年份、小数、
代码与普通正文数值不会因此成为引用。两张真实书页恢复了既有定义，原文及来源保持不变。

两行表格须有更强的表格尺度和下方空白才能排除页底代码。完全没有阅读内容的页面也可以
