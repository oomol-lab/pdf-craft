# 开启脚注时的结构分析验证

本验证使用固定双轮 OCR、开启脚注的初级页面处理与官方 `jev-1.14.0`。
内部工作点为 `risk >= 0.45`，直接比较通过概率与 `0.55`，不舍入、不按精修配额调节。
评分集为连续书籍片段共487页：475页不同来源的主集，加12页同源原生 PDF 对照。

## 当前结果

| 结果 | 全部487页 | 主集475页 |
| --- | ---: | ---: |
| 建议精修 | 123（25.26%） | 115（24.21%） |
| 审核通过 | 341 | 339 |
| 无可审核项 | 23 | 21 |
| 技术失败 | 0 | 0 |

逐页结合原图、原始两轮 OCR 文字与框，404页未发现正文/脚注流混淆，38页确认存在混淆，
45页暂不能确认。固定的404页中，55页建议精修，占 **13.61%**；去掉配对原生对照后，
对应为51/396，占12.88%。分母包含无可审核项，未通过重新划分样本降低比例。

这个核验只涉及 OCR 流归属，不等于全文准确、内容完整或其他结构决定正确；相邻页的
OCR 问题也可能影响当前页。13.61% 不是 JEV 的误送率，也不是完整487页或网站整体的送修率。
确认混淆的38页中仍有3页未送修，不能因统计时单列这些页面而掩盖漏送。未确认页也不当作正常页。

## 执行与证据

验证使用生产生成器和聚合器重建基础及补充请求，每批最多四题。完整请求相同的输入
复用对应的真实响应，改变的输入取得新响应；关键改善页与错误对照另以全新请求重复核验。
这属于受控回归，不代表487页均重新调用供应商，也不代表独立书籍上的准确率验证。

没有新增 OCR 请求、执行 LLM 精修、翻译或 PDF 回填。新增的数字墨迹观测来自同一原始
PDF 的局部渲染，原始 OCR 文字、框和来源身份仍在487页全部保留。原始数据没有被覆写。
本报告衡量建议送修，不证明后续 LLM 修复成功或最终排版已经验收。

## 上游采用的规则

- **原始局部窗口。** 页处理只读取本页与前后原始页，不读取相邻精修结果或评分，不增加全书等待。
  脚注别名先读取未修改身份快照，再写规范身份；窗口外未知起点保持未决。
- **引用与定义分开。** 上标、圈号、转义星号及唯一配对的句末压平数字保留印刷身份。
  定义索引不是印刷号码。清楚的数字加句点、右括号或成对括号可建立定义，即使正文标记
  没被 OCR 保留下来；裸数字仍需配对证据。年份、小数、缩写、代码和歧义重复不成为引用，
  不补造缺失正文标记。
- **页边数字。** 需要充分正文、栏外或居中位置、短数字尺度、引用与资产保护。
  居中页码与正文至少相隔1.5个数字框高度；横排侧页码还需排除首行列表对齐。
  竖排列观测或数字自身的堆叠比例可提供竖排证据，不能仅凭位置排除注释。
- **墨迹观测。** 对大片空白中的短数字，可在有面积上限的原始首轮图像裁剪中记录独立墨迹框。
  所有暗像素必须形成一个紧凑单行区域；分离行、边缘噪声或不一致尺寸保持未知。
  不使用二轮擦除后的图像证明原始空白，不依赖仅首页保留的封面图，不更改 vendor 的原始框。
  观测保存在 OCR 缓存并传给 JEV；不是 PCEX 格式字段，也不是自动修正数字的内容。
- **代码与章页脚。** 短代码需要足量正文或充足表格、明显下方空隙和外缘位置；两行表格须满足
  更强尺度与空白条件。章页脚还需页码、章号与短章名的受限语法。只有印刷物的页面须由
  低位同基线上的章页脚与远端代码共同证明。普通图注、正文同名、真实注释与孤立短标题不适用。
  正文和脚注共用排除投影，原始来源作为 ignored 保留。
- **出版记录。** 单独 ISBN 形态行与明确版次、印数单行共同建立局部版权页上下文，
  将这些独立字段保持为不同段落。普通叙述、单个日期、没有配套字段或多行框不构成依据。
  当前规则识别中文出版记录，不依赖全书 metadata 提取，也不声称校验了 ISBN 内容。
- **段界证据。** 实测首行信息优先。普通单行可从邻近同栏正文估计缩进，不要求右侧也缩进；
  含数学源码的单行使用一致的实际框高，不能按 LaTeX 字符数估算字宽。完成标点后的破折号
  不取消缩进。完整话轮或结束省略之后的新报告发言，可以独立成段；后置归属语、未完成词及
  引语外尚未完成的条件结构不能作为这项规则的断段依据。有限文字线索不代替通用语法分析。
- **行内数学续页。** 前页未完成的文字可以续接以行内公式开头的下一页，不能仅因首节点
  不是字符串而硬断开。同页段落、独立段落公式、纯数字编号与已结束句子保留原边界规则。
  公式旁的短连接词也可与同一印刷行结束：必须有明确句末标点、侧置关系、唯一匹配和
  随后可靠的新段缩进，不能只凭附近存在公式断段。
- **资产连接只判断一次。** Jointer 使用已有页几何判断文字与图表的连接，格式组装不重新推断。
  两段文字之间的独立资产不能取消下一行可靠的缩进；侧置资产的行宽形变仍有保护，公式仍是
  硬边界，连续正文仍能嵌入图表。已经采用的段落不能被后续较弱条件重新连接。

涉及新增排除和段界的来源均对照原图确认；这不等于逐页核验整套结构。
引用恢复也有原图存在注释、两轮 OCR 却都遗漏文字的边界：保留下来的结构审核通过，
不能被计作恢复了未识别文字。

## JEV 的局部事实协议

审核分别判断当前来源的印刷角色、定义、引用与段界，不把解释性语义等同于脚注。
完整主阅读校注、作者括注、独立图注、真正附属脚注和跨页续文需要区别对待。
未完成词与未完成语法结构分别判断；同一主题和完整句的延续不是强制连接的理由。

补充词续接或必要语法续接时，独立核验实际最近正文前驱和指定字面事实。两项共同成立
才支持这一条既有连接；不能跳过真实正文、图注或署名去寻找更早的匹配片段。
完整独立引语、可选后续行为和话题相关不证明语法依赖。补充证明不豁免其他段界、角色或引用错误。

居中数值的独立展示角色与普通句法完整性分开核验。仅在小数来源及其前后同页正文满足
实测居中、充分留白和同栏条件时发起问题；证明只作用于该处语法段界，不放过词内切断
或其他结构错误。普通整数编号、行内数值及缺少可靠周边来源的情况不采用此证明。

基础与补充请求共用用户提供的 executor、usage、重试与观察链路。任一应有批次缺失，
不能把部分成功冒充完整审核。没有完整判定不伪造通过，也不因供应商故障自动启动 LLM。

## 工程与结论边界

轻量测试覆盖两条投影、顺序解析、流式解析、来源不变性、页码反例、原始图像观测、
定义与引用分离、资产段界保留、引语外依赖、补充证明的独立性及缺失响应。
完整轻量回归为1720通过、6跳过，类型检查为0错误。共享算法的段界变化也核对关闭脚注
路线；本次没有重新测量该路线的整套供应商评分。

人工标签必须绑定具体输入。历史人工判断不能直接沿用为新上游的准确率分母，本报告
不提供完整487页的误送率或漏送率。新响应重复通过也不证明模型没有波动。

原始书籍、图像、响应、逐来源核验和研究过程保留在私有 worktree 的忽略目录中，不随包发布。
