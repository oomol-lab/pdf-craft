# 开启脚注时的 JEV 结构审核验证

本验证固定开启脚注的双轮 OCR 和初级页面分析，只改变 JEV 协议。评分集为连续书籍片段
共487页，其中475页为不同来源的主集，12页为同源原生 PDF 对照。模型为官方
`jev-1.14.0`，内部工作点为未舍入的 `risk >= 0.45`。

## 范围与结果

| 结果 | 页数 |
| --- | ---: |
| 建议精修 | 269（55.24%） |
| 审核通过 | 195 |
| 无可审核项 | 23 |
| 技术失败 | 0 |

每批最多四个具名问题，基础与补充共4,383个请求。精确相同的请求可以复用已有真实响应，
不能把重放计作新调用或独立重复实验。正式聚合器重放487页的具名响应后，最终路由均一致。
长字面重复使用可逆传输编码，曾超过供应商输入额度的九个页面均取得完整结果。

本轮没有执行 LLM 修复、翻译或 PDF 回填。建议精修不等于最终修复成功；55.24%也不等于
上游真实错误率。关闭脚注使用另一套输入与审核协议，不能直接比较两者的人工准确率。

## 人工核验与限制

累计核验61页，来自多文体抽样和定向反例，均已成为开发样本。新抽查先固定人工判断，再
查看模型分数；一旦用来调整协议，就不再视为独立验证集。

| 人工判断 | 页数 | 建议精修 | 未送修 |
| --- | ---: | ---: | ---: |
| 明确结构错误 | 30 | 29 | 1 |
| 明确正常 | 24 | 0 | 24 |
| 不确定 | 7 | 单列 | 单列 |

正常页中3页无可审核项。以上数字仅描述已核验页面，不能外推整本书、全部487页或线上
误送率与漏送率。部分原图用于确认版面，但不能把图上才看得到的事实当作文字审核器已知。

剩余漏送涉及竖排主阅读校释被第二轮 OCR 再次识别成细小脚注片段，局部归属判断仍可能
不稳定。独立摘录、跨栏和章末校释需要同时核对正文序列，不能仅凭小字号、页底或相同文字
直接删除。相同请求仍有分数波动；一个开发集的完整通过不代表之后不会出现误判。

原图、完整请求与响应、输入指纹及逐页审核记录保存在私有 worktree 的忽略目录，不随包
发布。其内容变更后，旧人工标签和旧模型响应不能直接继续充当新输入的验收依据。

协议说明见[JEV 结构审核](../design/jev-structural-review.md)。
