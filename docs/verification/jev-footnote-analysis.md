# 开启脚注时的结构分析验证

本验证使用固定的双轮 OCR、开启脚注的初级页面处理和官方 `jev-1.14.0` 局部审核协议。
初级页面结构保持固定；审核协议区分整块来源的印刷角色与文字的解释性含义，内部工作点为
`risk >= 0.45`。边界在通过概率口径直接比较，不因取补的浮点误差放过恰好位于阈值的页面。
评分集为连续书籍片段共487页，其中475页是不同来源的主集，12页为同源原生 PDF 对照。

## 结果与执行范围

| 结果 | 全部487页 | 主集475页 |
| --- | ---: | ---: |
| 建议精修 | 176（36.14%） | 168（35.37%） |
| 审核通过 | 288 | 286 |
| 无可审核项 | 23 | 21 |
| 技术失败 | 0 | 0 |

基础和补充共3,967个具名请求，每批最多四题。精确相同的请求可复用已有真实响应，
不能把重放计作新调用或独立重复实验。长字面重复使用可逆传输编码；样本中曾超过供应商
输入额度的九个页面均能取得完整结果。

没有新增 OCR、执行 LLM 修复、翻译或 PDF 回填。本表衡量当前协议建议精修的页面数量，
不是实际修复成功率，也不是网站整体费用估计。关闭脚注使用另一套输入与审核协议，
不能直接比较两者的人工准确率。

## 归属判定的针对性核验

在固定上游、模型和工作点下，采用相同边界规则重放原协议，建议精修为193页；当前协议
为176页。这是审核触发数量的对照，不能直接解释成实际修复页数。

| 已人工核验的来源事实 | 原协议误判数 | 当前协议误判数 |
| --- | ---: | ---: |
| 20个主阅读文字块被判为脚注 | 18 | 0 |
| 7个真实脚注文字块未判为脚注 | 1 | 1 |

这些是针对性开发样本，判断只涉及来源归属，不是随机抽样或整页正确性标签，不能外推为
487页的整体误报率、漏报率。7个真实脚注块分属两张已知错误页，两页均仍触发精修；其中
一个无编号续段尚未独立识别，不能宣称逐块召回完整。使用全新角色请求重复核验时，上表
结论保持一致，但其他临界页仍可在工作点两侧波动。

## 通过页的新增核验

按书籍确定性抽取20张此前未核验的通过页，每本最多两张。逐页对照原图和固定的
三页结构输入，发现4张存在可由归属编辑修复的错误：正文残片、图名或语言页脚误入
脚注流。当前协议将其中3张送修，仍漏掉1张短图名；其余16张未观察到结构错误，
当前均保持通过。这个按书籍分层的开发样本不是总体随机样本，不能用4/20或1/20
代表全书的真实错误率或漏判率。

补充的独立分节判断不依赖 OCR 已将标题标成 heading。对无明确起点的来源，短原文
只是候选，仍须分别确认独立分节和整块成员关系；普通句子或编号不能直接充当证明。
误入脚注的窄正文残片和独立图名也不因其被标为 citation 而合法。

全新请求重复核验中，两张正文残片的新增命中保持，语言页脚的分数仍靠近工作点，
短图名仍漏判。独立的定义、引用评分也会波动，不能将一次通过当作稳定无误的证明。
送修增加可能来自补获真实漏判；同样不能只凭触发数增加就认定质量提高。

## 引用对应的针对性核验

核验了6个曾仅因引用判断被送修的页面，未找到足以否决相应引用映射的具体证据。
引用审核需区分印刷 mark、内部 index 和 XML path，不得以正文未完、注释主题或其他块的
问题否决当前对应，也不要求每块正文都引用本页脚注。章末注释或缺少对应定义的标记
不强行关联；OCR 漏掉的定义文字不能凭空恢复。

当前协议不再因这6项送修。其中5项仍有可审核问题，按实际生产批次分别进行了3次
全新请求，15个有效结果均通过；另1页的无索引脚注流只有标点，没有真实定义或已有引用，
因此不产生引用问题。这些是已选定的开发案例，不代表总体误送率。

另以同一正常引用构造错目标、漏映射和替换移位三类对照，各进行3次全新请求，9个错误
结果均被拦截；正常对照的3次请求均通过。人工构造对照验证的是具体机制，不能代替真实
错误页的召回率，也不保证供应商未来评分稳定。

## 正文与出版附属物的局部核验

在出版附属物触发来源的定向核验中，确认了两处卷标题和一处说明书操作步骤属于主阅读内容，
却被判成了出版附属物。当前协议为这类已保留正文补充主阅读位置证明；三个误判来源均得到
纠正。只有一页因此解除送修，其余两页仍有独立错误，继续送修。

三个来源各进行3次全新证明请求，9次均取得主阅读证明；另一个真实页脚来源的3次请求
均未取得该证明。它们仅是针对性开发案例，不能据此估计整套样本的误送率或漏判率。
冻结的原有请求与评分继续保留，新增证明只改变同一来源的出版附属物风险。

目录条目的目的页码仍有被误判为当前页码的情况；其错误 citation 归属不能因另一项判断
减弱而被直接放行。语言页脚的评分也仍会波动，这些限制不由本次正文位置证明消除。

## 上游机制与证据

- 已知圈号、星号的 Markdown 转义和行内公式包装不改变其定义身份；有对应定义的正文
  标记采用同一识别规则。普通数字定义需要本页已有明确上标或唯一句末引用候选；
  重复候选、缩写、数学常数、小数和代码不提供推断依据。
- 页边数字须满足局部条件：正文栏外、充分的正文带尺度、无资产重叠、未被正文或引用提及。
  横排还需位于全部文字下方；侧边页码需有占主要文字量的实测竖排列证据。
  居中页码还需满足单行数字尺度、中轴对齐和至少两个数字框高度的正文间隔。
  原文、框和身份保留为可恢复的排除。被本规则选中的92个来源已查看
  原图：91个是印刷页码，另1个是被 OCR 误读为数字的裁切标记。页码证据主要集中在小说，
  不能据此外推其他文体。
- 窗口内已知脚注起点的别名使用未修改的初级身份快照。规范化前页不能使后页丢失起点；
  窗口外未知起点仍保持未决，不增加全书等待。

来源级视觉核验只确认这92个排除决定，不等于逐页核验整本书。JEV 校准时累计人工核验的
61页标签绑定其当时的输入与结构决定，不能直接沿用为更新后上游的准确率分母。当前不报告
全部487页的人工误送率或漏送率。

关闭脚注路线的487页基础审核请求与固定的改动前版本逐字相同。确定性测试覆盖两条初级
投影和无精修增量解析、跨页定义、原始来源保留、年份与正文数字反例、资产标签及未知候选。

## 剩余边界

送修比例仍较高。运行页眉页脚、无编号续文、单个 OCR 框容纳多条注释及图片旁独立文本
仍可能需要语义判断；JEV 分数也有波动。不能通过删除待审核文字、放宽结构要求或改变阈值
降低统计值，建议精修也不等于后续 LLM 已经能够修好该页。

审核通过不证明相对原图的内容完整性。来源核验中存在原图有注释、两轮 OCR 均未保留该
注释文字的页面；恢复其余已识别引用后，局部结构审核仍可能通过。缺失文字不在结构输入中，
不能将这种通过计作整页修复成功，也不能仅靠结构审核测量 OCR 漏字、漏块的比例。

反向也存在边界：结构审核可能把正文内的作者括注或连续排版的校注正文误判为页下注释。
来源核验已确认这类归属误判；不能为了降低送修数而将正确正文改入脚注流。

原图、完整请求和响应、输入指纹、逐来源核验与研究笔记保存在私有 worktree 的忽略目录，
不随包发布。输入或协议改变后，旧模型响应与人工判断不能冒充新输入的验收结果。

[上游动态修复](../design/upstream-dynamic-repair.md)。
