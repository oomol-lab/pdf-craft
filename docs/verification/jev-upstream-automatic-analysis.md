# 自动分析与 JEV 结构审核验证

本验证检查冻结 OCR、当前页面投影及关闭脚注的生产 JEV 协议。模型为官方
`jev-1.14.0`，工作点固定为未舍入的 `risk >= 0.52`。建议精修比例衡量调用范围，
不能单独代表审核准确性或上游质量。

## 样本与执行范围

评分集共487页：475个不同来源的主集页面，以及12页同源原生 PDF 对照。覆盖小说、插图书、
数学教材、学术论著、图录、竖排校释和复杂脚注文档；每本书使用连续片段，并保留直接相邻
原始上下文。原生对照不作为独立书籍样本重复计算人工质量。

当前英文模板通过官方 `jev-1.14.0` 完成487页新旧措辞成对验证，共3513次真实响应。
同一页中请求内容完全一致时共享本轮评分，改变或新增的请求分别执行，新旧先后顺序按页
交替；没有使用历史评分代替本轮调用。旧措辞建议精修57页，澄清后的措辞为58页。
两版共用阈值、证据和聚合算法，仅修改“关闭脚注时引用表示可以保留”的适用范围，
不再将其误写成所有归属错误的唯一条件。下表采用本轮澄清后结果，不挑选重复调用中的较优值。
原始 OCR、来源文字、框及页面处理决定保持不变。审核补齐当前/邻页的图片说明与位置，
并用独立事实核验现有连接，而不是改写页面投影来降低建议精修数量。

没有新增 OCR、执行 LLM 精修、翻译或 PDF 回填。本验证不代表后续修复与最终排版已经验收。
原书、图像、响应、人工核验与研究记录保留在私有 worktree 的忽略目录，不随包发布。

## 审核结果

| 评分结果 | 全部487页 | 主集475页 |
| --- | ---: | ---: |
| 判定需要精修 | 58（11.91%） | 56（11.79%） |
| JEV 通过 | 389 | 381 |
| 无可审核项 | 40 | 38 |
| 技术失败 | 0 | 0 |

无可审核项单列。来源归属、词界、句法及补充事实分别判断：既有连接是否跨入独立图注、
相邻两块是否同属一条编号指令、例题设定是否可保留在同一段等。角色题只保留原始文字、
来源身份和几何，不将 OCR 流或算法 ownership 当成角色答案。

图片说明使用当前格式的 title/caption，非展示 image.content 不回退为说明。邻页资产是
原始只读证据，不充当正文前驱；审核不读取邻页评分或精修结果，也不增加全书等待。

## 人工核验

当前已核验163页，包括123页正常、27页错误和13页不确定；原134页固定比较子集另行保留。历史问题若已由
上游修正，需要重新核对当前决定；原判断及修订依据继续保留。人工核验使用原图和同一局部
原始证据，作者措辞、转录遗漏和其他无法用结构编辑修复的问题单列。

| 人工判断 | 页数 | 判需精修 | 放行或无审核项 |
| --- | ---: | ---: | ---: |
| 可确认结构错误（保留原有争议标签） | 27 | 27 | 0 |
| 可确认正常 | 123 | 0 | 123 |
| 不确定或无法定性 | 13 | 6 | 7 |

正常页中11页没有可审核文字。27个错误标签中，数学条件与独立演算分行的一项仍有
验收边界争议，保留原标签；本轮新旧措辞都将其送修。固定163页标签上的误送、漏送均为零，
不等于487页全量零误差，也不能把与历史评分的差异归因于本次措辞澄清。

新旧最终判定仅一页不同。另行核对该页及相邻原图，确认存在页边标题保留为正文的归属
错误，新版该次将其送修；这份新增核验不混入原163页比较集。该处新旧措辞重复评分都能
跨越阈值，因此不能将单次多拦一页声称为稳定提升。

这些标签来自分层抽查与定向反例，不是独立随机盲测，不能外推为487页或网站的准确率。
已核验的插图前驱、脚注混接及空白页附属物案例均绑定具体来源与原图。补充核验可扩大
已知问题范围，但不改写固定比较子集。以全部487页为分母，已知正常误送为0（0%），保守计入的
已知漏送为0（0%）；其余未定性页面不能假定全部正确。
重复请求验证稳定性，也不等同于独立书籍验证。

## 工程验收

无网络测试覆盖来源不可变、图片展示字段及邻页资产证据、具体前驱定位、两项事实共同
成立、短页边与无文字页面的角色判断、同页闭合前驱证明的范围、例题证明的作用范围、编号指令与独立数学行的区别，以及缺失响应不能发布部分通过。
页面/JEV 相关轻量回归通过。两种模式共6487个请求完成离线对照：除获准修改的归属
说明外，原始证据、问题结构、字段顺序及固定响应下的判定保持一致；开启脚注的3920个
请求逐字不变。固定评分回放不等同于实际模型评分不变，措辞影响另由上述成对实测检查。
所有事实共用原 JEV executor、usage、请求观察与
重试链路；开启脚注的提示与聚合规则保持独立。

人工核验及来源证据必须随输入绑定，实际模型响应仍可能波动。需要扩大质量结论时，
继续积累未核验页，保留不确定判断，并核对结构编辑究竟能解决什么。
