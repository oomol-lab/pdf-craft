# 自动分析与 JEV 结构审核验证

本验证检查冻结 OCR、当前页面投影及关闭脚注的生产 JEV 协议。模型为官方
`jev-1.14.0`，工作点固定为未舍入的 `risk >= 0.52`。建议精修比例衡量调用范围，
不能单独代表审核准确性或上游质量。

## 样本与执行范围

评分集共487页：475个不同来源的主集页面，以及12页同源原生 PDF 对照。覆盖小说、插图书、
数学教材、学术论著、图录、竖排校释和复杂脚注文档；每本书使用连续片段，并保留直接相邻
原始上下文。原生对照不作为独立书籍样本重复计算人工质量。

当前生产协议的完整回归重新发起2,521个真实请求，全部返回 `jev-1.14.0`；没有复用历史评分。
原始 OCR、来源文字、框及页面处理决定保持不变。审核补齐当前/邻页的图片说明与位置，
并用独立事实核验现有连接，而不是改写页面投影来降低建议精修数量。

没有新增 OCR、执行 LLM 精修、翻译或 PDF 回填。本验证不代表后续修复与最终排版已经验收。
原书、图像、响应、人工核验与研究记录保留在私有 worktree 的忽略目录，不随包发布。

## 审核结果

| 评分结果 | 全部487页 | 主集475页 |
| --- | ---: | ---: |
| 判定需要精修 | 56（11.50%） | 54（11.37%） |
| JEV 通过 | 391 | 383 |
| 无可审核项 | 40 | 38 |
| 技术失败 | 0 | 0 |

无可审核项单列。来源归属、词界、句法及补充事实分别判断：既有连接是否跨入独立图注、
相邻两块是否同属一条编号指令、例题设定是否可保留在同一段等。角色题只保留原始文字、
来源身份和几何，不将 OCR 流或算法 ownership 当成角色答案。

图片说明使用当前格式的 title/caption，非展示 image.content 不回退为说明。邻页资产是
原始只读证据，不充当正文前驱；审核不读取邻页评分或精修结果，也不增加全书等待。

## 人工核验

固定比较使用134页现行人工判断，包括102页正常、22页错误和10页不确定。历史问题若已由
上游修正，需要重新核对当前决定；原判断及修订依据继续保留。人工核验使用原图和同一局部
原始证据，作者措辞、转录遗漏和其他无法用结构编辑修复的问题单列。

| 人工判断 | 页数 | 判需精修 | 放行或无审核项 |
| --- | ---: | ---: | ---: |
| 可确认结构错误（保留原有争议标签） | 22 | 21 | 1 |
| 可确认正常 | 102 | 0 | 102 |
| 不确定或无法定性 | 10 | 5 | 5 |

正常页中11页没有可审核文字。剩余一个旧错误标签涉及数学条件和演算的独立分行，
与允许独立数学展示的验收边界仍有争议，保留原标签保守计入漏送。这不是已确认全量零误差。

这些标签来自分层抽查与定向反例，不是独立随机盲测，不能外推为487页或网站的准确率。
另行核验的插图前驱案例用于确认具体连接错误，保留为补充记录，不混入固定比较分母。
重复请求验证稳定性，也不等同于独立书籍验证。

## 工程验收

无网络测试覆盖来源不可变、图片展示字段及邻页资产证据、具体前驱定位、两项事实共同
成立、例题证明的作用范围、编号指令与独立数学行的区别，以及缺失响应不能发布部分通过。
完整轻量回归、类型检查及 lint 均通过。所有事实共用原 JEV executor、usage、请求观察与
重试链路；开启脚注的提示与聚合规则保持独立。

人工核验及来源证据必须随输入绑定，实际模型响应仍可能波动。需要扩大质量结论时，
继续积累未核验页，保留不确定判断，并核对结构编辑究竟能解决什么。
