# 自动分析与 JEV 结构审核验证

本验证使用冻结 OCR 证据，检查自动分析、关闭脚注时的局部 JEV 协议及生产接线。
模型固定为官方 `jev-1.14.0`，内部工作点为未舍入的 `risk >= 0.52`。模型评分不是人工金标，
送修比例也不能单独代表上游质量或审核准确性。

## 样本与执行范围

评分集共487页：475个不同来源的主集页面，以及12页同源原生 PDF 对照。覆盖小说、插图书、
数学教材、学术论著、图录、竖排校释和复杂脚注文档；每本书使用连续片段，并保留相邻原始
上下文。原生对照不作为独立书籍样本重复计算人工质量。

原始 OCR 文字、来源框、顺序和身份不被改写。自动分析尊重公式硬边界，并利用可用的实际
首行像素观测；长单行的辅助缩进使用字高与邻近同栏正文边界，测不到则保持未知。含行内
数学源码不会因此失去像素观测，也不会把 LaTeX 字符长度当成实际行宽。

生产实现重建2,506个完整请求，与已保存模型响应的请求哈希逐项匹配，整页聚合一致。
这是精确请求重放，不是额外一轮全部重新调用供应商。新增事实检查也有独立新响应对照，
但复用了其余相同基底，不能说成多轮完全独立的端到端评估。

没有新增 OCR、执行 LLM 精修、翻译或 PDF 回填；因此不能据此声明最终译文或修复成果已经
通过视觉验收。原始书籍、响应、图像、审核记录与研究笔记保留在私有 worktree 生成产物中，
不随包发布。

## 审核结果

| 评分结果 | 全部487页 | 主集475页 |
| --- | ---: | ---: |
| 判定需要精修 | 69（14.17%） | 67（14.11%） |
| JEV 通过 | 378 | 370 |
| 无可审核项 | 40 | 38 |
| 技术失败 | 0 | 0 |

无可审核项单列，不冒充模型通过。局部协议分别判断基础结构及需要的事实证明：完整词或
句法结构被硬切、正文归属、独立图注/摘录、不同说话人的话轮、独立注释分节等。

## 人工核验

主集累计查看152页，其中18个历史判断对应的上游输入已改变，不能用于当前质量分母。
当前有效标签134页，另有323页尚未人工核验。标签包括分层抽查和定向反例，不是独立盲测。

| 人工判断 | 页数 | 判需精修 | 放行或无审核项 |
| --- | ---: | ---: | ---: |
| 可确认结构错误 | 28 | 27 | 1 |
| 可确认正常 | 96 | 0 | 96 |
| 不确定或无法定性 | 10 | 单列，不计入二分类分母 | 单列 |

已知错误检出为27/28（96.43%），已知正常误送为0/96。它们仅描述已核实页面，不是整套
487页或网站的准确率估计。正常页中11页没有可审核文字。部分人工判断需要原图确认排印，
不能用这些结果声称模型从相同文字中获得了未提供的像素事实。

剩余已知漏送涉及插页后正文、照片摘录及真实文字前驱之间的关系。严重 OCR 重复、漏字或
窗口外真实前驱不足时保持不确定；不通过改变标签、忽略来源或强制断段改善指标。

## 工程验收

无网络单元测试覆盖具名分数与旧浮点返回、失败/缺失批次、工作点边界、来源不变性、
公式前驱、重复来源保留代表、混合区域豁免限制、条件候选、跨页词续接及独立风险保留。
用户提供的 executor 继续限制实际供应商并发；请求重试、usage 与观察回调共用原链路。

合成正反例还区分普通配图正文、已有图注的重放、短标签、词尾、同一人继续发言、嵌套引用
和后置署名。反例只用于工程核对，不混进真实书籍的人工质量分母；保守限制停止某项豁免，
不等于模型自身已经正确识别了所有混合块。

同一输入仍可能出现分数波动，其他临界页不会因为一个检查改善而自动稳定。需要新模型、
新输入规则或新协议时，应继续核对精确输入、保存旧判断，并优先补充未核验页面。

判定规则见[JEV 结构审核](../design/jev-structural-review.md)，产品取舍见
[PDF 提取的流式设计](../design/pdf-extraction-streaming.md)。
