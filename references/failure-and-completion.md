# 失败、降级与有效成果

**约束范围：** 文档任务的失败恢复、译文缺失、来源定位和最终成功判定。修改相关处理、计数或回调时阅读。

## 可信结果与缺失

模型返回内容不代表业务完成。候选必须通过完整结构和业务校验，才能原子提交。
PCEX 的正文/脚注以作者意义的自然段为原子，不能按 bbox 拆成部分成功的译文。
EPUB 沿用自己的原子翻译片段，不把请求窗口或章节当成原子。

翻译或结构恢复失败时显式保留“无可信译文”；不能把源文本、空字符串或未校验的
部分映射标成成功。PCEX 以 coverage 的 preserved/缺失记录表达这一状态，原始层始终保留；
译文层中为保持结构对齐而保留的来源内容不是译文。替换展示退回源内容，双语只显示一次原文。
EPUB 不修改失败片段对应的源 XHTML，其余已接受片段照常提交。

## 有边界的恢复

TOC/章节集合失配使用带 missing_ids、unexpected_ids、page_indexes 的内部结构诊断。
先经 analysis/chapter_toc 决策撤回一次不兼容精修，再必要时显式协调目录与已生成章节；
不可因这种全局元数据错误就将全部 OCR 正文降为图片。目录重建不更改章节内容或重编号，
仅提升失效父项下的幸存子项；多余章节 ID 不能静默消除。页面降级后，恢复结果必须同时
携带匹配的 TOC，且只允许移除实际降级页上的失效锚点。真正全书降级仍失败。

重试用于完成同一次业务操作，不得暗中嵌套额外的批次到单项重试或无期限质量循环。
网络重试与响应校验修复是不同层；追加阅读前页是正常业务推进，不是失败重试。
纯文本翻译没有可靠质量判据时不臆造语义修复循环。

可恢复失败的决策发生在尝试预算耗尽后，先让调用者知道拟采用的降级，再提交它。
分析增强可退回统计、原生元信息或未经精修的算法结果。JEV 未评估不能伪造低分，也不能
把服务故障自动扩大为全页 LLM 修复。采用局部精修前必须保证跨页正文、脚注和引用关系
仍然成立；恢复范围无法可靠隔离时撤回整批精修。原算法自身非法不能冒充合法 fallback。

PDF 提取采用有限层级恢复：可信精修结果 → 经验证的传统结果 → 受影响页原页图片 →
无法渲染时的明确占位。最后两级由提取编排层负责，绕过损坏的段落/脚注对象图；也覆盖
无 LLM 精修时的结构分析失败。不能用强制拆开正常自然段来替代业务修复。
升级到 page_image 必须重新通过 analysis 决策，渲染失败再以 pdf_render 请求 page_placeholder；
允许较轻的 algorithm_result 不代表允许丢弃页级结构。能定位时按跨页段落、脚注与引用关系
闭合影响范围，包括自然段中间仅有图片/表格的全部资产页，不能只连接两端文字页；
无可信分析图时也保留跨资产页的文字前驱。缺少可信定位时保守扩大到整批。其余内容按连续未降级页段重新解析，不能跨过
被替换页建立连接。每段最多重新解析一次；失败段整体转成原页图片，不循环修复坏对象。
原 OCR 缓存不改写，已经发出的精修前预览不撤销、不重复通知。最终成果按实际采用的内容
重新结算，包括 OCR 成功但后续退成图片的页；全部主要页降级仍报任务级失败。

OCR 失败可保留页图片；页面渲染失败可能只有文本占位。PDF 回填失败可保留原 PDF 页。
仅上述有限升级可以继续处理降级失败；最终资源写入/文件发布失败、取消、用户回调异常和
不可继续的服务错误继续传播，不能吞掉或启动无界恢复。

## 来源与影响

失败操作的目标与降级的影响范围是两回事：一个段落失败可能引发整页保留。
回调提供独立的公开值快照，不泄露内部工作对象，不依赖临时目录生命周期。
自然段的来源包含全部跨页区域，使用 PageGeometry 与实际图片尺寸解释坐标，禁止以
占位几何冒充真实几何。未知精确故障点时诚实提供整页或整批目标，上下文不能标成失败。

EPUB 提供归档成员路径及片段身份；只在可靠时提供 CFI。HTML 的定位降级不妨碍翻译。
字段、导航、资源和复用页眉模板使用各自身份，不假设每种业务都对应单一页码。
跨进程传递仍保留来源、类别和错误摘要，不能依赖裸异常对象恰好可序列化。

## 用户任务的成功

“全局”指调用者发起的完整任务，不是内部步骤。完成文件包装不等于主要工作成功。
全部页只因错误留下图片/占位的 PDF 提取、全部主要片段因错误缺失译文的翻译、全部应回填
内容未写入而只剩原 PDF 的回填，都必须最终失败，即使调用者允许所有局部降级。
书名、导航、元信息或页眉成功不能掩盖正文/脚注的全部失败；增强分析全降级则不应抹掉
正常完成的主要工作。

区分正常完成、因错误降级和无需处理。缓存、合法同文、源模式正常输出原文、原生图片
不是降级；不能通过文本差异推断成功。真正无目标与目标全部失败分别处理。
流式增量统计最终被采用的结果，在 EOF/flush 后结算；撤回的候选从成功中移除。
不得为统计而预加载全书，也不能因候选列表已被失败清空，就走无工作复制的成功路径。


PDF 回填也必须保护仍需保留的来源：异常大文本框若覆盖无关图片或未翻译正文，
不得因该文本译文成功便擦掉它们。回填前几何冲突以 `pdf_fill/source_geometry` 请求
`original_pdf_page`，明确目标 bbox 与跨页自然段闭包。接受后绕过这些页的全部擦除和填充，
复制实际原页；不输出虚假的行排版回调，且纳入全部回填失败统计。

输入不执行强制完整性门禁；在实际操作处按原有异常和 ErrorPolicy 处理失败。
独立 `assert_*` 函数仅供用户主动调用，成功返回 None，失败传播原始异常，不修复输入。

## 并发终止原因

同一执行组首次观察并记录的 NonContinuableError 是唯一终止原因。记录必须发生在
关闭请求池、取消兄弟任务和等待清理之前，不能按已完成任务集合的遍历顺序重新选择。
不同请求池组成的业务执行组通过执行上下文共享首因，独立任务不共享该上下文。
取消及收尾继续完成；后续失败和派生取消不能替换首因或改写其 cause/context 链。
没有致命首因时保留真正的外部取消、自行取消及普通失败语义。测试用屏障固定交错，
覆盖取消先收集、竞争致命错误、收尾失败和资源收敛，并遍历异常图检查 HTTP 状态及回环。

## LLM 验收宪法

LLM 的中间响应以可恢复的有效成果为准，不以模型逐字符遵守表面格式为目标。
没有歧义、算法可以修复的差异，应先恢复再校验和采纳，不能平白要求模型重新生成、浪费
请求和 token。有歧义、缺少必要信息或不能证明恢复正确时，才进入有限重试。保持结构、身份、
正文及最终产物约束，不靠删断言或猜测缺失内容制造成功。

可恢复性必须覆盖采纳后的变换：适配层声明会替换的临时节点，统一恢复时将边界分隔放在
替换后仍保留的字段，不能只验证替换前的拼接文字。空槽位恢复出实际内容时，其两侧位置
不能随意互换。持久化继续忠实保存结果，不复用交互层的空白归一化来改写已采纳内容。

friendly XML 排版、空白标准化和 canonical 恢复统一使用 `transformer/whitespace.py`，
复用现有 block/inline 分类；根据来源上下文处理 CSS document whitespace，不再用 Unicode
范围的 `\s+` 代替语义。具体支持边界、标准链接及例外见 `docs/zh-CN/LLM_ACCEPTANCE.md`。
