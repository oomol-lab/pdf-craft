# 失败、降级与有效成果

**约束范围：** 文档任务的失败恢复、译文缺失、来源定位和最终成功判定。修改相关处理、计数或回调时阅读。

## 可信结果与缺失

模型返回译文不代表结构化交付完成。译文不接受任何前置审查或门禁；原始回答保留，
fill 与比较使用同一份工程视图。结构化候选必须通过真实交付要求的验收，才能原子提交。
遵守[翻译与 fill 的职责硬边界](translation-fill-boundary.md)。
PCEX 的正文/脚注以作者意义的自然段为原子，不能按 bbox 拆成部分成功的译文。
EPUB 沿用自己的原子翻译片段，不把请求窗口或章节当成原子。

翻译或结构恢复失败时显式保留“无可信译文”；不能把源文本、伪造的空字符串或未校验的
部分映射标成成功。已通过整组最终全文和结构验收的空译文是可信结果，不能与失败哨兵 None 混淆。PCEX 以 coverage 的 preserved/缺失记录表达这一状态，原始层始终保留；
译文层中为保持结构对齐而保留的来源内容不是译文。替换展示退回源内容，双语只显示一次原文。
EPUB 不修改失败片段对应的源 XHTML，其余已接受片段照常提交。

翻译全文采用共用归一化比较视图，具体规则见翻译职责硬边界；不在恢复层追加另一套空白门禁。

## 有边界的恢复

印刷目录页识别不分配章节 ID。传统分析、精修和关联校验在内部候选上完成；采用结果后，
目录和章节使用同一份最终标题集合，furniture 使用最终占用与标题。删除、合并或降级标题
不能触发撤回精修或页面降级。旧派生 toc.xml 不作为输入，无法证明输入／配置有效就重算。
辅助 furniture 的生成或校验故障在独立边界按 analysis 错误策略提出 `omit_furniture`；
获准时仅移除无效 furniture，保留已采用正文。严格策略传播原始错误，不能进入章节恢复。
归档校验中的 FurnitureValidationError 同样不代表正文页损坏；存储故障、取消继续传播。
真正的 TOC/章节失配仍带 missing_ids、unexpected_ids、page_indexes 诊断并拒绝发布，
不可因这种全局元数据错误就将全部 OCR 正文降为图片。页面恢复先产出已采用内容，再生成目录。

重试用于完成同一次业务操作，不得暗中嵌套额外的批次到单项重试或无期限质量循环。
网络重试与响应校验修复是不同层；追加阅读前页是正常业务推进，不是失败重试。
翻译阶段不设内容验收或修复循环，也不得要求批译文满足 envelope 或公式身份协议。
所有返回译文保留原文，并以同一工程视图进入 fill；结构分配、公式对应与完整性失败只在 fill 层有限修复，
不能反向要求重译。调用层网络故障另按传输预算处理。fill 耗尽后沿用 failure_log_id
保留原始译文及本单元参与的真实请求现场，已成功兄弟单元不重试。

可恢复失败的决策发生在尝试预算耗尽后，先让调用者知道拟采用的降级，再提交它。
分析增强可退回统计、原生元信息或未经精修的算法结果。JEV 未评估不能伪造低分，也不能
把服务故障自动扩大为全页 LLM 修复。唯一的输入超限路由例外是精修已启用且 JEV 明确返回
HTTP 400 `error_type=max_tokens_exceeded`：停止本页 JEV，进入既有 LLM 精修，不伪造评分
或增加 JEV 请求预算；其他失败仍按原策略处理。精修候选的程序验收只读取精修后的当前页完整结果，不读取精修前结构，遵守
[页精修验收的单页硬边界](page-refinement-validation.md)。禁止读取邻页归属或采用结果来
拒绝当前页，禁止试装后继初级结果、跨页属性一致性门禁及向本页反馈邻页修复结论。
单页组装使用事务，失败不能泄露半份内容；事务探测不得包含邻页语义批准。
精修后结果自身确实非法时据其内部一致性错误决定有限恢复，回退本身不构成合法性证明。
跨资产页保留输出流游标，不保留用于否决本页的初级语义尾部契约。
已有采用页保持权威，局部失败不得按邻页语义依赖闭包撤回其他精修成果。
原算法自身非法不能冒充合法 fallback。

PDF 提取采用有限层级恢复：可信精修结果 → 经验证的传统结果 → 受影响页原页图片 →
无法渲染时的明确占位。最后两级由提取编排层负责，绕过损坏的段落/脚注对象图；也覆盖
无 LLM 精修时的结构分析失败。不能用强制拆开正常自然段来替代业务修复。
升级到 page_image 必须重新通过 analysis 决策，渲染失败再以 pdf_render 请求 page_placeholder；
允许较轻的 algorithm_result 不代表允许丢弃页级结构。能定位时按跨页段落、脚注与引用关系
闭合影响范围，包括自然段中间仅有图片/表格的全部资产页，不能只连接两端文字页；
无可信分析图时也保留跨资产页的文字前驱。初始错误缺少可信定位时才保守扩大到整批；已有采用结果不能按这些传统语义依赖扩大范围。
其余内容按连续未降级页段逐页重建，不能跨过被替换页建立连接。
每页在本次重建中只尝试一次：局部失败回滚当前页，保全有效前缀，仅该页转为原页图片，
后续页以新的输出游标继续，未绑定的续段显式保全。已采用页直接读取，不先运行原始分析
重新批准它；其他页使用同一初级顺序与当前页验收。收尾／发布错误及指向其他页的错误
继续传播，不能借此撤回整段。恢复不重放已交付回调，也不循环修复坏对象。
原 OCR 缓存不改写。PDF 提取正文／脚注回调交付处理后页面形成的已闭合自然段，启用精修时不先发精修前预览。
最终TOC/层级/目录排除不要求回写已交付自然段；不等待无关工作，不在末尾重放。
最终 PCEX 仍须归档校验，但文件收尾不构成内容流屏障；不能将回调作为成功信号。最终成果按实际采用的内容
重新结算，包括 OCR 成功但后续退成图片的页；全部主要页降级仍报任务级失败。

OCR 失败可保留页图片；页面渲染失败可能只有文本占位。PDF 回填失败可保留原 PDF 页。
Poppler stderr 仅作为诊断日志，不按 `Syntax Error` 等文字判定操作失败；底层仍拒绝
非零退出，页面渲染还须完整解码图片。正常退出且图片可解码时保留页面，不因字体诊断
升级为占位，也不承诺所有字形完全还原。
仅上述有限升级可以继续处理降级失败；最终资源写入/文件发布失败、取消、内容交付回调异常和
不可继续的服务错误继续传播，不能吞掉或启动无界恢复。

## 来源与影响

失败操作的目标与降级的影响范围是两回事：一个段落失败可能引发整页保留。
回调提供独立的公开值快照，不泄露内部工作对象，不依赖临时目录生命周期。
自然段的来源包含全部跨页区域，使用 PageGeometry 与实际图片尺寸解释坐标，禁止以
占位几何冒充真实几何。未知精确故障点时诚实提供整页或整批目标，上下文不能标成失败。

EPUB 提供归档成员路径及片段身份；只在可靠时提供 CFI。HTML 的定位降级不妨碍翻译。
字段、导航、资源和复用页眉模板使用各自身份，不假设每种业务都对应单一页码。
跨进程传递仍保留来源、类别和错误摘要，不能依赖裸异常对象恰好可序列化。

## 用户任务的成功

“全局”指调用者发起的完整任务，不是内部步骤。完成文件包装不等于主要工作成功。
全部页只因错误留下图片/占位的 PDF 提取、全部主要片段因错误缺失译文的翻译、全部应回填
内容未写入而只剩原 PDF 的回填，都必须最终失败，即使调用者允许所有局部降级。
书名、导航、元信息或页眉成功不能掩盖正文/脚注的全部失败；增强分析全降级则不应抹掉
正常完成的主要工作。

区分正常完成、因错误降级和无需处理。缓存、合法同文、源模式正常输出原文、原生图片
不是降级；不能通过文本差异推断成功。真正无目标与目标全部失败分别处理。
流式增量统计最终被采用的结果，在 EOF/flush 后结算；撤回的候选从成功中移除。
不得为统计而预加载全书，也不能因候选列表已被失败清空，就走无工作复制的成功路径。


PDF 回填不按源框面积比例或重叠判定整页失败，不沿跨页段落扩展这种几何门禁。
已有可信译文应继续尝试写回；来源大框可能损伤图片或未翻译文字的问题，需在来源几何
或擦除机制中按证据解决。实际替换校验、排版与合成失败仍遵循原错误策略及有效成果统计，
不得为取消几何门禁而吞掉真正的失败，或输出未写入的虚假预览。

输入不执行强制完整性门禁；在实际操作处按原有异常和 ErrorPolicy 处理失败。
独立 `assert_*` 函数仅供用户主动调用，成功返回 None，失败传播原始异常，不修复输入。

## 并发终止原因

同一执行组首次观察并记录的 NonContinuableError 是唯一终止原因。记录必须发生在
关闭请求池、取消兄弟任务和等待清理之前，不能按已完成任务集合的遍历顺序重新选择。
不同请求池组成的业务执行组通过执行上下文共享首因，独立任务不共享该上下文。
取消及收尾继续完成；后续失败和派生取消不能替换首因或改写其 cause/context 链。
没有致命首因时保留真正的外部取消、自行取消及普通失败语义。测试用屏障固定交错，
覆盖取消先收集、竞争致命错误、收尾失败和资源收敛，并遍历异常图检查 HTTP 状态及回环。

## LLM 验收宪法

LLM 的中间响应以可恢复的有效成果为准，不以模型逐字符遵守表面格式为目标。
没有歧义、算法可以修复的差异，应先恢复再校验和采纳，不能平白要求模型重新生成、浪费
请求和 token。有歧义、缺少必要信息或不能证明恢复正确时，才进入有限重试。保持结构、身份、
正文及最终产物约束，不靠删断言或猜测缺失内容制造成功。

全文验收只比较归一后的内容。

fill Loop 从模型原始 XML 提取内容，两侧调用同一个共用字符串比较函数；不先物化格式再向模型追责。
具体工程视图和字符规则统一见[翻译与 fill 的职责硬边界](translation-fill-boundary.md)。
Loop 成功后的格式物化和择机公式来源复用必须保全已接受内容；工程转换故障保留诊断并按现有错误策略报告，不能触发模型修复。隐藏 annotation 不能掩盖实际显示内容丢失。持久化忠实保存已采用结果，不把归一化比较视图写成最终内容。

请求内 block/inline ID 共用唯一身份空间，结构验收和最终采用解释为同一映射，重复身份
不得形成部分成功。friendly XML 排版和来源分段仍可使用 `transformer/whitespace.py`
及既有 block/inline 分类；这些运输规则不授予字段空白归属或 CSS 上下文额外的验收权限。
说明见 `docs/zh-CN/LLM_ACCEPTANCE.md`。

PAGE 单元的完成是页处理及必要校验的事实，不是后续组段/产物发布成功；后续恢复继续经错误策略报告，不重开或覆盖已完成页事件。operation 完成仍要求所有实际成果校验与发布成功。EPUB 内容通知只释放完整且未被自身/外层原子 owner 拒绝的片段，不按整章等待，也不泄露可能撤回的半份内容。


## 进度是辅助观察

`on_extraction_event` / `on_translation_event` 及其初始化、预扫描、计数更新、专用状态存储和
收尾仅负责观察。普通异常停用本次进度报告，最多记录一次有界诊断，不撤销或阻断主流程成果。
预估与实际单元数、词数不一致只记录各类预估、实际及差值，不作为交付门禁，不补造单元、
词数或 100%。诊断日志自身失败也不能阻断交付。统计一致性由离线回归检验。
取消、进程终止信号继续传播；模型、解析、内容完整性、主业务队列/存储、产物写入与发布、
`on_body` / `on_footnote` / `on_metadata` 等内容交付回调和 ErrorPolicy 的失败语义不变。
不得在整个转换外层吞异常，也不得把内容回调改成进度通知的容错行为。

## fill 诊断的提交生命周期

启用 `LLM.failure_log_path` 时，每轮请求、回答及修复反馈先写临时日志。所有 repair Loop 的
异常退出都归档，而不只在预算耗尽时归档；请求、解析、校验或反馈构造抛异常时，最后一轮
尚未完成验收的回答也保留，并在 summary 中记录原始异常和堆栈，通过 `failure_log_id` 定位。
原始异常和现有 ErrorPolicy 继续传播，不把程序错误改成修复成功。

翻译 fill 的模型验收成功只是中间状态。每个 group 的诊断继续保留至关联来源根的适配、
回填、提交及直接内容回调全部成功；跨根 group 等全部相关根提交后才清理。并发 group
通过独立诊断作用域及稳定来源身份关联，不把日志对象或原始 DOM 放进磁盘重排结果。
提交失败归档参与本次提交的尚未关闭的 group；不会收集其他无关 group 或已提交成功组。
未能关联到具体提交的整体取消/后续整本包装失败不追溯已清理的成功日志。
成功日志不永久归档，关闭诊断配置不写文件；诊断 I/O 失败不覆盖业务异常。上述生命周期
不增加模型阶段、重试预算或内容门禁，也不改变翻译、XML fill 与来源结构的职责边界。
