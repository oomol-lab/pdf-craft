# 页精修验收的单页硬边界

**约束范围：** PDF 页精修的程序候选校验、纠错、采用，以及组装、批处理、离线工具中承担同等职责的代码。
这是用户明确确定的不可让步约束。只有用户明确修改此决定后才可变更，Agent 不得自行以质量、安全或兼容为由增设例外。

## 程序只拿到精修后的当前页

验收器只接收精修后的当前页完整结果，既没有邻页参数，也没有精修前的当前页结构参数。
可以按结果自身携带的来源与范围契约检查 schema、身份/范围自洽、页内阅读顺序、
页内段落属性、当前页脚注定义和引用的一致性；不能回读精修前结构来批准或否决它。
本页连接声明的字段形状可以检查，但不能读取邻页来证明它是否语义正确。

禁止验收、纠错或采用代码读取任何邻页原文、几何、初级归属、段落属性、脚注成员、
JEV 评分、精修结果、已采用页记录，或由这些信息派生的摘要、缓存和边界契约。
精修前的当前页结构同样禁止访问。不得把旧结构藏入 initial、canonical、source.origin、
闭包或附带元数据再读取；上述信息不能作为本页拒绝、降级、字段回写、重试或等待的依据。
禁止试装下一页初级结果，禁止拿前页最终脚注成员来批准本页续接，禁止跨页比较
role/level 或 outgoing/incoming 字段来否决本页。

结果自身的页内完整性保护继续保留。范围重叠、缺少必要字段、无成员脚注或本页引用目标
不存在等仍应由本页验收拒绝。固定精修后的当前页结果，改变精修前结构或任何邻页信息，
验收结论必须保持不变。内容来源的基础编解码不授予按旧页语义重审的权限。

## 模型上下文与程序验收隔离

输入桥接层可以读取、传递当前及直接相邻的不可变初级证据，供 JEV/LLM 理解当前页。
这只是上下文运输，不授予桥接层依据邻页作语义验收或回写本页的权限。
模型请求不读取邻页 JEV 评分、精修结果或采用结果，也不等待这些结果。

首次请求和修复请求遵循相同隔离规则。不得将已采用邻页的归属、活动脚注正文或合法前驱
清单反馈给当前页模型，形成新的跨页修复 loop。模型修复继续使用原始请求上下文，程序反馈只来自精修后当前页的内部一致性检查。

## 组装落实声明，不重新审批

有序组装按当前页提交的本页阅读顺序、段落边界及续接声明追加内容，负责输出身份的
分配、引用实体化和恰好一次交付。可以使用输出流的句柄、编号和追加游标；不得打开邻页
快照或检查输出流中来自其他页的文本、归属、role/level，以决定当前页是否正确。
不能将前页的语义结论藏入游标、canonical 别名或初级尾部契约，再变相约束当前页。

页协议应表达当前页自己的连接操作，而不是要求模型提交一个必须由程序到邻页验证其
脚注成员资格的来源范围。旧 predecessor 范围协议及相关门禁需要一起调整，不能只吞掉异常。
段落及脚注的跨页延续与页内段落边界是不同概念；组装契约应分别表达，避免重复字段成为跨页一致性门禁。
没有可用输出游标时，物化策略必须保全当前页内容、显式处理未绑定状态；不能伪造已连通，
也不能据此诊断邻页对错并回退当前页。具体结构需在实现时明确并测试。

事务、磁盘故障处理、取消、回调异常和最终产物的纯格式/引用完整性校验仍然必要。
它们不能执行跨页语义重审，不能把邻页不可靠变成当前页的语义拒绝或连锁撤回。
正文/脚注闭合后的交付仍受流式约束；不为补齐邻页语义证明扩大窗口或等待全书。

## 已发现的相反实现：待移除偏移

截至 main `7f97b8d`，以下是现存偏移清单，不是允许保留的兼容行为：

- `chapter/page_repair.py` 的 `_validate_reading_boundary`：按下一页正文、括号及本页几何拒绝本页归属。
- 同文件的邻页 `available` / `shared_ids` 与 `_validate_shared_citations`：从其他页推定已知身份，锁住本页定义和成员。
- 同文件的 `_compile_citations`：复制邻页定义的起点信息，并以初级 `origin_page_index` / index 形态禁止本页修改跨页起点。把邻页猜测预先放进当前页对象，也不能使它变成验收事实。
- 同文件的 `all_pages` 事务、`_compile_page_connections` 与跨页 `restore_streams`：候选验收读取共享页集合，批入口同样必须拆除这种依赖。
- `chapter/assembly.py::_bind_incoming`：查询 `adopted` 邻页，要求 predecessor 范围属于保留脚注且匹配活动脚注。本次 citation-on smoke 由此失败。
- `PageAssembly.validate`：试装前文、当前页和下一页初级结果，并比较跨资产页的角色/层级尾部契约。
- `_Paragraphs.append` / `page_analysis._restore_layouts`：当输入横跨页边界时，前驱存在性、双向连接和 role/level 比较会变成跨页语义门禁。页内检查应留在本页编译器。
- `chapter/primary.py::bind_local_result`：依据初级邻页映射别名，且在透明资产页场景回写本页 incoming。它不一定直接抛错，但仍会覆盖独立决策。

模型上下文组装、传统无精修分析、多页文件读取与输出流机械追加，不应被误算成这些程序验收门禁；
也不能借它们的名字包装新的邻页验收。实现尚未完成调整，文档约束不能被解读为代码已经满足。
实现调整完成后移除已解决的偏移清单，保留硬约束和反耦合测试要求。

## 必须固化的反耦合测试

- 固定精修后的当前页结果，改变精修前的当前页结构及邻页原文、归属、评分、ID、精修/采用结果，验收结论保持不变。
- 验收器 API 仅接收精修后当前页；用访问即抛错的旧页结构和邻页对象证明验收、采用和纠错不会偷读。
- 阻塞邻页 JEV/LLM，当前页请求与本页验收仍可完成；不把正常的输出顺序/自然段闭合与页级验收混为一谈。
- 使用本次 citation-on 的原始 OCR 和回答：出版提示的邻页归属不能成为当前页的拒绝理由，无需额外跨页模型请求。
- 保留结果自身的范围重叠、无成员定义、引用不存在等负例；取消旧结构和跨页门禁不能让页内非法结果通过。
- 纯组装保持内容、稳定身份与恰好一次通知；没有游标的入口截取及其他未绑定情况有明确测试，不能靠读邻页补救。
- 删除或改写要求“邻页冲突必须拒绝当前页”的旧测试。不得让旧测试迫使实现恢复禁止的门禁。
